# Vibe Kanban

> 一款面向开发者的可视化项目管理工具，集成 git 仓库和 Claude Code、Amp 等编程智能体。

## 快速开始

无需安装，直接运行：

```bash
npx vibe-kanban
```

该命令将在本地启动应用并自动在浏览器中打开。

常用入口命令：

```bash
npx vibe-kanban --help
npx vibe-kanban --version
npx vibe-kanban review --help
npx vibe-kanban mcp --help
```

## 什么是 Vibe Kanban？

Vibe Kanban 是一款专为开发者打造的现代项目管理工具。它通过看板式任务管理帮助您组织编程项目，同时提供与 git 仓库和 AI 编程智能体的深度集成。

### ✨ 核心特性

**🗂️ 项目管理**

- 添加 git 仓库作为项目（支持已有仓库或创建新仓库）
- 自动 git 集成和仓库验证
- 跨所有文件的项目搜索功能
- 每个项目可自定义 setup 和开发脚本

**📋 任务管理**

- 通过看板式面板创建和管理任务
- 任务状态跟踪（待办、进行中、已完成）
- 丰富的任务描述和备注
- 支持多个 AI 智能体执行任务

**🤖 AI 智能体集成**

- **Claude**：高级 AI 编程助手
- **Amp**：强大的开发智能体
- **Echo**：简单的测试/调试智能体
- 创建任务后立即启动智能体执行
- 支持后续任务执行，实现迭代式开发

**⚡ 开发工作流**

- 为每次任务尝试创建独立的 git worktree
- 查看智能体所做更改的 diff
- 将成功的更改合并回主分支
- 变基任务分支以保持最新
- 手动文件编辑和删除
- 集成开发服务器支持

**🎛️ 开发者工具**

- 从文件系统浏览和验证 git 仓库
- 在您偏好的编辑器中打开任务 worktree（VS Code、Cursor、Windsurf、IntelliJ、Zed）
- 实时执行监控和进程控制
- 单独或批量停止正在运行的进程
- 任务完成声音通知

## 工作原理

1. **添加项目**：导入已有的 git 仓库或创建新仓库
2. **创建任务**：定义需要构建或修复的内容
3. **AI 执行**：让编程智能体在隔离环境中处理您的任务
4. **审查更改**：通过 git diff 查看具体修改了什么
5. **合并结果**：将成功的更改合并到主代码库中

## 核心功能

Vibe Kanban 提供完整的项目管理体验，包含以下核心能力：

**项目仓库管理**

- 管理编程项目的完整增删改查操作
- 自动 git 仓库检测和验证
- 初始化新仓库或导入已有仓库
- 项目级文件搜索功能

**任务生命周期管理**

- 创建、更新和删除带有丰富描述的任务
- 通过可自定义的状态工作流跟踪任务进度
- 一键创建任务并立即启动 AI 智能体执行
- 任务尝试跟踪，附带详细的执行历史

**AI 智能体执行环境**

- 独立的 git worktree，用于安全的代码实验
- 实时执行监控和活动日志
- 进程管理，可停止单个或全部进程
- 支持后续执行以迭代优化解决方案

**代码变更管理**

- 查看任务执行期间所有更改的详细 diff
- 分支状态监控，跟踪与主分支的差异
- 一键将成功的更改合并回主分支
- 自动变基以保持任务分支最新
- 手动文件删除和清理功能

**开发集成**

- 直接在您偏好的代码编辑器中打开任务 worktree
- 启动和管理开发服务器以测试更改
- 浏览本地文件系统以添加新项目
- 服务可用性健康监控

## 配置

Vibe Kanban 支持通过配置系统进行自定义：

- **编辑器集成**：选择您偏好的代码编辑器
- **声音通知**：自定义完成提示音
- **项目默认设置**：设置默认的 setup 和开发脚本

## 技术架构

- **后端**：Go + Chi Web 框架
- **前端**：React + TypeScript
- **数据库**：SQLite 本地数据存储
- **Git 集成**：原生 git 操作进行仓库管理
- **进程管理**：基于 Go goroutine 的执行监控

## 系统要求

- Node.js（用于 npx 执行）
- Git（用于仓库操作）
- 您偏好的代码编辑器（可选，用于打开任务 worktree）

## 支持平台

- Linux x64
- Windows x64
- macOS x64（Intel）
- macOS ARM64（Apple Silicon）

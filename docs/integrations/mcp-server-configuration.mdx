<Note>
本页面介绍如何在 Vibe Kanban **内部**为编程智能体配置 MCP 服务器。如需将外部 MCP 客户端连接到 Vibe Kanban 的 MCP 服务器，请参阅 [Vibe Kanban MCP 服务器](/integrations/vibe-kanban-mcp-server)指南。
</Note>

## 概述

MCP 服务器通过标准化协议为编程智能体提供额外的功能。你可以为 Vibe Kanban 中的每个编程智能体配置不同的 MCP 服务器，使其能够访问浏览器自动化、远程日志访问、通过 Sentry 进行错误追踪或从 Notion 获取文档等专用工具。

## 访问 MCP 服务器配置

1. 在 Vibe Kanban 界面中导航到 **Settings**
2. 在设置侧边栏中点击 **MCP Servers**
3. 从 **Agent** 下拉菜单中选择你要配置 MCP 服务器的编程智能体

Vibe Kanban 为热门 MCP 服务器提供一键安装。点击卡片即可将预配置的 MCP 服务器插入到 JSON 配置中。

## 添加自定义 MCP 服务器

你也可以通过手动配置来添加自己的 MCP 服务器：

<Steps>
<Step title="选择编程智能体">
从 **Agent** 下拉菜单中选择你要配置 MCP 服务器的编程智能体。
</Step>

<Step title="更新服务器配置 JSON">
在 **Server Configuration (JSON)** 编辑器中，添加你的自定义 MCP 服务器配置。JSON 将显示所选智能体的当前配置，你可以修改它以包含额外的服务器。

示例添加：
```json
{
  "mcpServers": {
    "existing_server": {
      "command": "npx",
      "args": ["-y", "some-existing-server"]
    },
    "my_custom_server": {
      "command": "node",
      "args": ["/path/to/my-server.js"]
    }
  }
}
```
</Step>

<Step title="保存并测试">
更新 JSON 配置后：

1. 点击 **Save** 应用更改
2. 通过使用具有 MCP 功能的智能体来测试配置
3. 检查智能体日志以排查任何连接问题

<Check>
这些更改会更新编程智能体的全局配置文件，即使你停止使用 Vibe Kanban，配置也会持续保留。
</Check>
</Step>
</Steps>

## 最佳实践

<Tip>
**服务器选择**：选择能够补充编程智能体主要功能的 MCP 服务器。例如，对于专注于 Web 开发的智能体，可以使用 Playwright。
</Tip>

<Tip>
**限制 MCP 服务器数量**：避免为单个编程智能体添加过多的 MCP 服务器。过多的服务器和工具会因选项过多而降低编程智能体的有效性。
</Tip>

<Steps>
<Step title="运行 Amp">
  ```bash
  npx -y @sourcegraph/amp
  ```
</Step>

<Step title="按照登录指引操作">
  按照提示完成身份验证流程。更多详情请参阅 [Amp 使用手册](https://ampcode.com/manual#install)。
</Step>

<Step title="启动 Vibe Kanban">
  完成身份验证后，启动 Vibe Kanban：

  ```bash
  npx vibe-kanban
  ```

  现在你可以在创建任务尝试时选择 Amp。
</Step>
</Steps>

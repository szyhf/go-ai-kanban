<Steps>
<Step title="运行 OpenAI Codex">
  ```bash
  npx -y @openai/codex
  ```
</Step>

<Step title="按照登录指引操作">
  按照提示完成身份验证流程。请按照 [OpenAI 帮助中心](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan)的身份验证说明，将 Codex 与你的 ChatGPT 计划配合使用。

  或者，你可以通过设置 `OPENAI_API_KEY` 环境变量，通过 OpenAI API 使用 Codex。更多详情请参阅 [OpenAI 文档](https://developers.openai.com/codex/pricing/#use-an-openai-api-key)
</Step>

<Step title="启动 Vibe Kanban">
  完成身份验证后，启动 Vibe Kanban：

  ```bash
  npx vibe-kanban
  ```

  现在你可以在创建任务尝试时选择 OpenAI Codex。
</Step>
</Steps>

## 自定义配置目录

默认情况下，Codex 将其配置和会话数据存储在 `~/.codex` 中。如果你已使用 `CODEX_HOME` 环境变量配置了自定义位置，Vibe Kanban 会自动检测并使用该位置。

```bash
# 示例：使用项目特定的 Codex 配置
export CODEX_HOME=/path/to/custom/codex
npx vibe-kanban
```

这适用于以下场景：
- 项目特定的 Codex 配置
- 分离工作和个人配置
- 自定义自动化设置

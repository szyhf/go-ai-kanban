---
title: "Azure Repos 集成"
description: "连接 Azure Repos，直接从 Vibe Kanban 创建 Pull Request 并管理工作流"
---

Vibe Kanban 与 Azure Repos 集成，让你可以直接从任务尝试中创建 Pull Request。此集成依赖于系统上已安装并完成身份验证的 [Azure CLI (`az`)](https://learn.microsoft.com/en-us/cli/azure/) 及其 Azure DevOps 扩展。

## 设置

在从 Vibe Kanban 创建 Pull Request 之前，你需要手动安装和配置 Azure CLI。

### 安装 Azure CLI

请按照适用于你操作系统的[官方安装说明](https://learn.microsoft.com/en-us/cli/azure/install-azure-cli)进行操作：

- **macOS**：`brew install azure-cli`
- **Windows**：从 Azure CLI 文档下载并运行 MSI 安装程序
- **Linux**：使用发行版的包管理器或安装脚本

### 安装 Azure DevOps 扩展

Azure DevOps 扩展为 Azure CLI 添加了仓库和 Pull Request 命令。运行以下命令：

```bash
az extension add --name azure-devops
```

### 身份验证

1.  **登录 Azure**：运行以下命令，按照提示通过网页浏览器完成身份验证：
    ```bash
    az login
    ```

2.  **配置默认值**（可选但推荐）：设置默认的组织和项目，以避免每次命令都指定它们：
    ```bash
    az devops configure --defaults organization=https://dev.azure.com/{your-org} project={your-project}
    ```

## 支持的 URL 格式

Vibe Kanban 支持现代和传统两种 Azure DevOps URL 格式：

- **现代格式**：`https://dev.azure.com/{org}/{project}/_git/{repo}`
- **传统格式**：`https://{org}.visualstudio.com/{project}/_git/{repo}`

HTTPS 和 SSH 远程 URL 均受支持。

## 创建 Pull Request

Azure CLI 准备就绪后，你可以直接从任务中创建 Pull Request：

1.  打开一个包含你要合并更改的任务。
2.  点击 **Create PR** 按钮。
3.  将出现一个对话框，预填充以下内容：
    *   **标题**：从任务标题派生。
    *   **描述**：从任务描述派生。
    *   **目标分支**：更改的目标分支（默认为仓库的默认分支或尝试中指定的分支）。
4.  点击 **Create** 在 Azure Repos 上创建 PR。

如果操作成功，任务状态将更新，并提供新 Pull Request 的链接。

## 创建项目

点击 **Create Project** 按钮，从以下两个选项中选择：
- **From existing git repository**：浏览文件系统并从按最近活动排序的 Git 仓库列表中选择
- **Create blank project**：从零开始创建一个新的 Git 仓库

每个项目代表一个 Git 仓库。创建完成后，你可以配置 setup 脚本、开发服务器脚本和其他设置。

<Note>
创建项目后，你需要点击右上角的设置按钮来配置项目脚本和设置。
</Note>

## 项目设置

创建项目后，你可以通过点击右上角的设置按钮来访问项目设置。在这里，你可以配置项目的各个方面。

### Setup 脚本

Setup 脚本会在编程代理执行之前运行。这对于安装依赖非常有用，例如你可以运行 `npm install` 或 `go mod download`。这可以节省时间，因为你的代理不需要再去发现这些命令还没有被执行。

<Note>
每次编程代理执行时，它都会在一个 [git worktree](https://git-scm.com/docs/git-worktree) 中运行，该工作区通常不包含你的依赖、配置、.env 等文件。
</Note>

### 开发服务器脚本

开发服务器脚本在你从[预览](/core-features/testing-your-application)部分点击"Start Dev Server"按钮时运行。这对于在编程代理运行后快速审查工作成果非常有用。

### Cleanup 脚本

Cleanup 脚本会在编程代理完成一轮工作后运行。你可以使用这些脚本来整理工作区、删除临时文件或执行任何执行后的清理工作。例如，你可以运行 `npm run format` 来确保代码格式正确。可以把它当作 git pre-commit hook 来使用。

### 复制文件

以逗号分隔的需要从原始项目目录复制到 worktree 的文件列表。这些文件会在 worktree 创建之后、setup 脚本运行之前被复制。适用于环境特定的文件，如 `.env`、配置文件和本地设置。

<Warning>
请确保这些文件已被 gitignore，否则它们可能会被提交！
</Warning>

创建项目后，点击项目看板页面右上角的**加号 (+) 图标**，或使用键盘快捷键 **`c`** 来添加任务。

创建任务时有两个选项：

- **Create Task**：将任务添加到看板，但不启动编程代理
- **Create & Start**：创建任务并立即使用默认编程代理和当前分支启动

## 使用任务标签

<Frame>
<img src="/images/screenshot-task-tag-autocomplete.png" alt="任务标签自动补全下拉菜单，显示输入 @ 符号后可用的标签" />
</Frame>

添加任务时，你可以使用任务标签插入可复用的文本片段：

1. 在任务描述或后续消息中输入 `@`
2. 开始输入标签名称来筛选可用的标签
3. 从下拉菜单中选择一个标签来插入其内容

<Note>
任务标签通过提供常见任务结构的可复用文本片段来节省时间。在[任务标签](/configuration-customisation/creating-task-tags)指南中了解更多。
</Note>

## 启动已有任务

<Frame>
<img src="/images/vk-new-task-attempt.png" alt="任务尝试创建对话框，显示代理配置和变体选择选项" />
</Frame>

当你打开一个尚未尝试过的任务时，你会看到任务标题、描述和一个显示"no attempts yet"的尝试列表。点击**加号 (+) 按钮**来创建任务尝试并配置：

- **Agent profile**：从可用代理中选择（如 CLAUDE_CODE、GEMINI、CODEX）。你在设置中的默认配置会被预先选中。
- **Variant**：如果你选择的代理有变体，请选择合适的变体（如 DEFAULT、PLAN）。
- **Base branch**：指定代理应该从哪个分支开始工作。默认选中你当前的分支。

<Tip>
使用 **Create & Start** 可以一步完成添加任务并立即用默认设置创建任务尝试。
</Tip>

<Note>
要监控任务的执行过程，请参阅[监控任务执行](/core-features/monitoring-task-execution)。要了解何时可能需要多次尝试，请参阅[新任务尝试](/core-features/new-task-attempts)。
</Note>

## 通过 MCP 客户端创建任务

<Warning>
这不是创建任务的常规方法，但对于批量创建任务、从其他系统迁移、使用具有额外项目上下文的 AI 助手，或让编程代理创建新任务等场景非常有用。
</Warning>

任务也可以通过编程方式使用编程代理或 MCP（Model Context Protocol）客户端（如 Claude Desktop 或 Raycast）来创建。此方法特别适用于：

- 基于现有数据或项目规格**批量创建任务**
- 从 Linear、GitHub Issues 或 Jira 等**其他系统迁移**
- 从项目计划或需求文档**自动生成任务**

<Tip>
有关详细的设置说明和示例，请参阅 [Vibe Kanban MCP Server](/integrations/vibe-kanban-mcp-server) 文档。
</Tip>

### MCP 任务创建示例

配置好 MCP 客户端后，你可以根据项目描述创建多个任务：

```
I need to implement user authentication with:
- Email/password registration
- Login with session management  
- Password reset functionality
- Email verification
- Protected route middleware

Please create individual tasks for each component.
```

MCP 客户端将根据此描述自动在你的 Vibe Kanban 项目中生成结构化任务。

## 理解任务列

任务从"To do"列开始，并根据进度自动移动：

| 操作 | 列 |
|------|------|
| 任务创建 | To do |
| 任务尝试启动 | In Progress |
| 任务尝试完成（成功或失败） | In Review |
| 任务尝试已合并 | Done |
| PR 在 GitHub 上已合并 | Done |

<Info>
你可以手动拖拽任务到不同的列，但这不会触发任何功能。任务移动主要由编程代理的操作和 GitHub 集成（每 60 秒轮询一次）驱动。
</Info>

This guide walks you through setting up Vibe Kanban locally for development and testing.

## Prerequisites

Before you begin, ensure you have:

- **Go** 1.24+
- **Node.js** 20+ and **pnpm**
- **Git**

## Step 1: Clone the Repository

```bash
git clone https://github.com/BloopAI/vibe-kanban.git
cd vibe-kanban
```

## Step 2: Install Dependencies

```bash
pnpm install
```

## Step 3: Start Development Server

```bash
pnpm run dev
```

This starts both the Go backend and the React frontend with hot-reload:

- **Frontend**: `http://localhost:3000` (Vite dev server)
- **Backend**: auto-assigned port (typically `3001`)

The frontend automatically proxies API requests to the backend.

<Info>
The backend uses SQLite and will auto-initialize the database on first run. If no database exists, it copies seed data from `dev_assets_seed/`.
</Info>

## Step 4: Verify

Open [http://localhost:3000](http://localhost:3000) in your browser. You should see the Vibe Kanban interface.

## Development Commands

| Command | Description |
|---------|-------------|
| `pnpm run dev` | Start backend + frontend |
| `pnpm run local-web:dev` | Start frontend only |
| `pnpm run backend:dev:watch` | Start backend only |
| `go test -race ./...` | Run Go tests |
| `go vet ./...` | Run Go static analysis |
| `pnpm run format` | Format all code (Go + frontend) |
| `pnpm run lint` | Lint all code |

## Project Structure

| Path | Description |
|------|-------------|
| `cmd/server/` | Go application entrypoint |
| `internal/` | Go backend (domain, handlers, services) |
| `packages/local-web/` | React frontend |
| `packages/web-core/` | Shared frontend components |
| `shared/` | TypeScript type definitions |

## Troubleshooting

<AccordionGroup>
<Accordion title="Port already in use">
Set custom ports via environment variables:

```bash
FRONTEND_PORT=3001 BACKEND_PORT=3002 pnpm run dev
```
</Accordion>

<Accordion title="Go build errors">
Ensure you're using Go 1.24+:

```bash
go version
```

Download dependencies:

```bash
go mod download
```
</Accordion>

<Accordion title="Frontend build errors">
Clear the cache and reinstall:

```bash
rm -rf node_modules
pnpm install
```
</Accordion>
</AccordionGroup>

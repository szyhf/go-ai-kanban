列表视图提供了以表格方式查看所有事项的功能，包括处于隐藏状态的事项。它适合一次性审查大量事项并获取项目的完整概览。

## 访问列表视图

要切换到列表视图，点击看板上方标题中的 **All** 标签。

<Frame>
  <img src="/images/cloud/status-tabs.png" alt="Status tabs showing Active, All, Backlog, and Cancelled" />
</Frame>

| 标签 | 显示内容 |
|-----|---------------|
| **All** | 所有状态的事项（包括隐藏） |
| **Backlog**、**Cancelled** 等 | 仅显示特定隐藏状态中的事项 |

要返回看板视图，点击 **Active** 标签。

## 列表布局

列表视图中的事项按状态分组。每个状态分区显示：

- 带颜色指示器的**状态名称**
- 该状态的**事项数量**
- **可折叠分区** - 点击展开或折叠

<Frame>
  <img src="/images/cloud/list-layout.png" alt="List view showing status sections with issues grouped by status" />
</Frame>

### 事项行详情

列表中的每行显示：

- **Simple ID** - 事项标识符（例如 ISS-1）
- **Title** - 事项标题
- **Workspace 指示器** - 显示事项是否有关联的 workspace
- **创建时间** - 事项创建距今的时间（例如"12d"表示 12 天）

点击任意行打开完整的[事项面板](/cloud/issues)。

## 列表视图中的多选

列表视图支持多选以进行批量操作。每行在鼠标悬停到其左边缘时会出现复选框。

### 选择方式

- **复选框** - 将鼠标悬停在行的左边缘显示复选框，然后点击选择
- **Cmd/Ctrl + Click** 行以切换其选中状态
- **Shift + Click** 行以选择从上次选中行到当前行的范围
- **X** 切换当前打开事项的选中状态
- **Shift + J / ↓** 或 **Shift + K / ↑** 向下或向上扩展选择一行
- **Cmd/Ctrl + A** 选择所有可见事项
- **Escape** 清除选择

被选中的行会高亮显示。当选择两个或更多事项时，屏幕底部会出现**批量操作栏**，提供更改状态、优先级、负责人或删除的选项。完整详情请参见[选择多个事项](/cloud/issues#selecting-multiple-issues)。

## 筛选和排序

筛选栏在列表视图和看板视图中工作方式相同：

- **Search** - 按标题查找事项
- **Priority** - 按优先级筛选
- **Assignee** - 按团队成员筛选
- **Tags** - 按标签筛选
- **Sort** - 更改事项排列顺序

详见[筛选与排序](/cloud/filtering)。

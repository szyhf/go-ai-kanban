组织设置页面让你管理 Cloud 组织、邀请团队成员以及配置组织级别的设置。

<Frame>
  <img src="/images/cloud/organization-settings-page.png" alt="Organization Settings page showing members and settings" />
</Frame>

## 访问组织设置

打开组织设置：

1. 点击左侧边栏底部的**头像图标**
2. 点击你的组织名称旁边的**设置图标** (<Icon icon="gear" />)

<Frame>
  <img src="/images/cloud/user-menu-settings.png" alt="User menu showing settings icon next to organisation" />
</Frame>

## 组织选择

在设置页面顶部，你可以：

- **切换组织** - 使用下拉菜单选择不同的组织

<Frame>
  <img src="/images/cloud/organization-switcher.png" alt="Organization switcher dropdown showing multiple organisations" />
</Frame>

<Info>
如果你是多个组织的成员，在这里切换会改变你正在查看和编辑的组织设置。
</Info>

### 个人组织

首次注册时，系统会为你创建一个个人组织，其中包含一个**初始项目**。个人组织有一些限制：

- 无法邀请其他成员
- 无法删除
- 仅你自己可以访问

## 待处理邀请

<Note>
此部分仅对**管理员**可见，且仅适用于非个人组织。
</Note>

待处理邀请部分显示所有已发送但尚未接受的邀请：

- **邮箱地址** - 被邀请的人
- **状态** - 等待接受
- **过期时间** - 邀请在 7 天后过期
- **撤销** - 如需要可取消邀请

### 撤销邀请

撤销待处理邀请：

1. 在列表中找到该邀请
2. 点击 **Revoke** 按钮
3. 邀请链接将不再有效

## 成员

成员部分显示所有有权访问组织的人员：

<Frame>
  <img src="/images/cloud/members-section.png" alt="Members section showing member list with Invite Member button" />
</Frame>

| 列 | 说明 |
|--------|-------------|
| **名称** | 成员的显示名称和头像 |
| **角色** | Admin 或 Member |
| **操作** | 角色变更、移除（仅限 Admin） |

### 成员角色

| 角色 | 权限 |
|------|-------------|
| **Admin** | 完全访问权限 - 管理成员、邀请、设置，删除组织 |
| **Member** | 访问项目和 Issue，无法管理组织设置 |

### 更改成员角色

<Note>
只有 Admin 可以更改成员角色。
</Note>

1. 在列表中找到该成员
2. 点击其名称旁边的角色下拉菜单
3. 选择新角色（Admin 或 Member）
4. 更改立即生效

### 移除成员

<Warning>
移除成员会立即撤销他们对组织中所有项目的访问权限。
</Warning>

1. 在列表中找到该成员
2. 点击 **Remove** 按钮
3. 在提示时确认移除

### 邀请新成员

邀请他人加入你的组织：

1. 点击 **Invite Member** 按钮
2. 输入其邮箱地址
3. 选择其角色（Admin 或 Member）
4. 点击 **Send Invitation**

<Frame>
  <img src="/images/cloud/invite-member-dialog.png" alt="Invite Member dialog with email and role fields" />
</Frame>

他们将收到一封包含加入链接的电子邮件。邀请在 7 天后过期。

## 账单

<Note>
此部分仅对非个人组织的**管理员**可见。
</Note>

账单部分为现有客户提供了在 Vibe Kanban 账户门户中管理账单的链接。

点击 **Manage Billing** 在新标签页中打开账单门户，你可以：
- 查看当前订阅
- 更新付款方式
- 查看发票和账单历史

## 危险操作区

<Warning>
危险操作区中的操作具有破坏性且无法撤销。
</Warning>

<Frame>
  <img src="/images/cloud/danger-zone.png" alt="Danger Zone section with Delete Organization button" />
</Frame>

### 删除组织

<Note>
只有 Admin 可以删除组织。个人组织无法删除。
</Note>

删除组织：

1. 滚动到**危险操作区**部分
2. 点击 **Delete**
3. 在提示时确认删除
4. 所有项目、Issue 和数据将被永久删除

<Warning>
删除组织会移除：
- 组织中的所有项目
- 所有 Issue 及其历史记录
- 所有团队成员的访问权限
- 所有待处理的邀请

此操作无法撤销。
</Warning>

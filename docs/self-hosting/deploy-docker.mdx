本指南介绍如何使用 Docker 在任意 Linux 服务器上部署 Vibe Kanban。此方式适用于任何云服务提供商（AWS、DigitalOcean、Hetzner 等）或本地服务器。

## 前提条件

- 一台 Linux 服务器，具备以下条件：
  - 已安装 **Docker**
  - 至少 **2GB 内存**（推荐 4GB）
  - **5GB 磁盘空间**
- 一个指向你服务器的**域名**（可选，用于远程访问）

## 第 1 步：构建 Docker 镜像

克隆 Vibe Kanban 仓库并构建：

```bash
git clone https://github.com/BloopAI/vibe-kanban.git
cd vibe-kanban
docker build -t vibe-kanban .
```

## 第 2 步：运行容器

```bash
docker run -d \
  --name vibe-kanban \
  -p 8080:8080 \
  -e PORT=8080 \
  -e HOST=0.0.0.0 \
  vibe-kanban
```

在浏览器中打开 `http://your-server:8080` 即可访问 Vibe Kanban。

<Warning>
默认情况下，服务器绑定到 `0.0.0.0`，任何主机都可以访问。在生产环境部署中，请使用带有身份验证的反向代理。
</Warning>

## 第 3 步：配置反向代理（推荐）

在生产环境中，建议使用 Caddy 或 nginx 等反向代理来实现 HTTPS：

### 使用 Caddy

创建 `Caddyfile`：

```text Caddyfile
your-domain.com {
    reverse_proxy vibe-kanban:8080
}
```

然后更新 Docker 运行命令，将容器加入 Caddy 网络并设置 `VK_ALLOWED_ORIGINS`：

```bash
docker run -d \
  --name vibe-kanban \
  --network caddy \
  -e PORT=8080 \
  -e HOST=0.0.0.0 \
  -e VK_ALLOWED_ORIGINS=https://your-domain.com \
  vibe-kanban
```

## 环境变量

| 变量 | 默认值 | 说明 |
|----------|---------|-------------|
| `PORT` | `0`（自动） | 服务器端口 |
| `HOST` | `127.0.0.1` | 服务器主机地址 |
| `VK_ALLOWED_ORIGINS` | （无） | 以逗号分隔的允许来源列表，用于 API 请求 |

## 更新

更新到新版本：

```bash
cd vibe-kanban
git pull origin main
docker build -t vibe-kanban .
docker stop vibe-kanban && docker rm vibe-kanban
docker run -d \
  --name vibe-kanban \
  -p 8080:8080 \
  -e PORT=8080 \
  -e HOST=0.0.0.0 \
  vibe-kanban
```

## 监控

### 查看日志

```bash
docker logs -f vibe-kanban
```

### 健康检查

```bash
docker ps
curl http://localhost:8080/api/sessions
```

## 故障排除

<AccordionGroup>
<Accordion title="SSL 证书问题">
如果使用 Caddy，它会自动从 Let's Encrypt 获取 SSL 证书。请确保：
- 你的域名 DNS 已正确指向服务器
- 防火墙已开放 80 和 443 端口
</Accordion>

<Accordion title="API 请求返回 403">
设置 `VK_ALLOWED_ORIGINS` 环境变量为你的前端 URL：
```bash
VK_ALLOWED_ORIGINS=https://your-domain.com
```
</Accordion>

<Accordion title="构建时内存不足">
如果构建因内存错误失败，可以添加交换空间：
```bash
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
```
</Accordion>
</AccordionGroup>

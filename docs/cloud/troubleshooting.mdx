本页面涵盖你可能遇到的 Vibe Kanban Cloud 常见问题及其解决方法。

## 登录问题

<AccordionGroup>
<Accordion title="无法登录">
**可能的原因：**
- 弹出窗口拦截器阻止了 OAuth 窗口
- 网络连接问题
- 浏览器扩展干扰

**解决方案：**
1. 为 localhost 禁用弹出窗口拦截器
2. 检查网络连接
3. 尝试暂时禁用浏览器扩展
4. 尝试使用其他浏览器
5. 清除浏览器缓存和 Cookie
</Accordion>

<Accordion title="OAuth 窗口无法打开">
**可能的原因：**
- 弹出窗口拦截器已启用
- 浏览器安全设置

**解决方案：**
1. 查看浏览器地址栏中是否有被拦截的弹出窗口通知
2. 允许 `localhost` 的弹出窗口
3. 尝试右键点击登录按钮并选择"在新标签页中打开"
</Accordion>

<Accordion title="GitHub/Google 返回'Access denied'错误">
**可能的原因：**
- 你点击了"Deny"而不是"Authorize"
- 你的组织有应用限制（GitHub）

**解决方案：**
1. 重新尝试并点击 **Authorize** 或 **Allow**
2. 如果使用 GitHub 组织账户，请联系管理员批准该应用
</Accordion>

<Accordion title="登录到了错误的账户">
**可能的原因：**
- 你的浏览器登录了不同的 GitHub/Google 账户

**解决方案：**
1. 退出 Vibe Kanban
2. 前往 [github.com](https://github.com) 或 [google.com](https://google.com) 并退出登录
3. 使用正确的账户登录
4. 返回 Vibe Kanban 并重新登录
</Accordion>

<Accordion title="会话持续过期">
**可能的原因：**
- 网络问题阻止令牌刷新
- 浏览器阻止 Cookie

**解决方案：**
1. 检查网络连接
2. 确保 localhost 已启用 Cookie
3. 尝试退出后重新登录
</Accordion>
</AccordionGroup>

## 组织问题

<AccordionGroup>
<Accordion title="无法创建组织">
**可能的原因：**
- 网络连接问题
- 你尚未登录

**解决方案：**
1. 确认你已登录（检查角落中的头像）
2. 检查网络连接
3. 尝试刷新页面
</Accordion>

<Accordion title="看不到我被邀请的组织">
**可能的原因：**
- 你尚未接受邀请
- 你使用了不同的邮箱登录
- 邀请已过期

**解决方案：**
1. 检查邮件中的邀请链接并点击
2. 确认你使用的是被邀请时的邮箱登录
3. 请组织管理员重新发送邀请
</Accordion>

<Accordion title="无法离开组织">
**可能的原因：**
- 你是唯一的管理员

**解决方案：**
1. 先将另一个成员提升为管理员
2. 然后你就可以离开
3. 如果没有其他人需要，也可以删除组织
</Accordion>
</AccordionGroup>

## 团队成员问题

<AccordionGroup>
<Accordion title="邀请邮件未收到">
**可能的原因：**
- 邮件被归入垃圾邮件/垃圾箱
- 输入了错误的邮箱地址
- 邮件发送延迟

**解决方案：**
1. 检查垃圾邮件/垃圾箱
2. 在待处理邀请列表中确认邮箱地址正确
3. 重新发送邀请
4. 尝试使用不同的邮箱地址
</Accordion>

<Accordion title="邀请链接不工作">
**可能的原因：**
- 邀请已过期（7 天后）
- 邀请已被取消
- 链接被复制不完整

**解决方案：**
1. 请对方重新发送邀请
2. 确保你点击的是邮件中的完整链接
</Accordion>

<Accordion title="新成员看不到项目">
**可能的原因：**
- 他们使用了不同的邮箱登录
- 浏览器缓存问题

**解决方案：**
1. 确认他们使用的是被邀请时的邮箱登录（检查个人资料）
2. 让他们刷新页面
3. 让他们退出后重新登录
</Accordion>
</AccordionGroup>

## 项目和看板问题

<AccordionGroup>
<Accordion title="项目无法加载">
**可能的原因：**
- 网络连接问题
- 同步延迟

**解决方案：**
1. 检查网络连接
2. 刷新页面
3. 退出后重新登录
</Accordion>

<Accordion title="更改未同步">
**可能的原因：**
- 网络连接断开
- 临时同步问题

**解决方案：**
1. 检查网络连接
2. 刷新页面——你的更改应该还在
3. 如果更改丢失，你可能需要重新输入
</Accordion>

<Accordion title="无法删除状态列">
**可能的原因：**
- 该列包含事项

**解决方案：**
1. 先将所有事项移到其他列
2. 检查隐藏视图中的事项（使用"All"状态标签页）
3. 然后删除空列
</Accordion>

<Accordion title="拖放不工作">
**可能的原因：**
- 排序模式未设为"Manual"
- 浏览器问题

**解决方案：**
1. 检查排序下拉菜单——选择"Manual"以启用拖放
2. 尝试刷新页面
3. 尝试使用其他浏览器
</Accordion>
</AccordionGroup>

## 事项问题

<AccordionGroup>
<Accordion title="找不到某个事项">
**可能的原因：**
- 活跃的筛选器隐藏了该事项
- 事项在隐藏列中

**解决方案：**
1. 点击筛选栏中的 **Clear All** 重置筛选
2. 使用"All"状态标签页查看隐藏列中的事项
3. 尝试搜索事项 ID 或标题
</Accordion>

<Accordion title="事项更改未保存">
**可能的原因：**
- 网络问题
- 你关闭面板太快

**解决方案：**
1. 编辑后稍等片刻再关闭面板（自动保存有短暂延迟）
2. 检查网络连接
3. 刷新并检查更改是否已保存
</Accordion>

<Accordion title="无法将某人分配到事项">
**可能的原因：**
- 他们不是组织成员

**解决方案：**
1. 先邀请他们加入组织
2. 他们接受后，将出现在负责人列表中
</Accordion>
</AccordionGroup>

## GitHub 集成问题

<AccordionGroup>
<Accordion title="GitHub 集成不工作">
**可能的原因：**
- GitHub App 未安装
- 仓库未连接

**解决方案：**
1. 前往组织设置 → GitHub Integration
2. 如果尚未安装 GitHub App，请安装
3. 确保仓库已授予访问权限
</Accordion>

<Accordion title="Pull Request 未关联到事项">
**可能的原因：**
- 分支名称不包含事项 ID
- PR 在集成设置之前创建

**解决方案：**
1. 在分支名称中包含事项 ID（例如 `TASK-123-feature`）
2. 或在 PR 标题中包含事项 ID
3. 新的 PR 应该会自动关联
</Accordion>

<Accordion title="代码审查不可用">
**可能的原因：**
- 该仓库未启用代码审查

**解决方案：**
1. 前往组织设置 → GitHub Integration
2. 为该仓库启用"Code Review"
</Accordion>
</AccordionGroup>

## 通用问题

<AccordionGroup>
<Accordion title="页面无法加载">
**解决方案：**
1. 刷新页面
2. 清除浏览器缓存
3. 尝试使用其他浏览器
4. 重启 Vibe Kanban（`npx vibe-kanban`）
</Accordion>

<Accordion title="一切都很慢">
**可能的原因：**
- 网络连接问题
- 打开了太多浏览器标签页

**解决方案：**
1. 检查网络连接
2. 关闭不需要的浏览器标签页
3. 刷新页面
</Accordion>

<Accordion title="数据似乎过期">
**解决方案：**
1. 刷新页面以强制同步
2. 检查网络连接
3. 退出后重新登录
</Accordion>
</AccordionGroup>

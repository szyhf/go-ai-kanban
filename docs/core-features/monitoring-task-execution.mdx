当你启动任务时，主面板提供了执行过程中所有操作的实时可见性。你可以观察代理如何思考问题、采取行动以及响应你的反馈。

</Frame>

## 执行过程中发生了什么

当你启动任务尝试时，Vibe Kanban 会编排多个步骤来创建隔离环境并执行你的任务：

1. **Git Worktree 创建**：为此次任务尝试创建一个隔离环境
2. **Setup 脚本运行**：你在项目设置中定义的 setup 脚本会自动运行
3. **代理执行**：编程代理使用标题和描述来处理你的任务
4. **实时监控**：通过任务界面中的流式日志查看进度
5. **后续提问**：在执行完成后继续对话以优化结果

### Git Worktrees

Vibe Kanban 使用 Git worktrees 为每个任务尝试创建隔离环境。这些环境是临时的，在执行完成后会自动清理。

<Info>
Worktrees 确保任务尝试之间不会相互干扰，也不会影响你的主工作目录。
</Info>

## 执行流程

### 1. Setup 脚本

你会看到的第一条日志是你的项目 setup 脚本正在运行（如果已配置）。它会在代理开始工作之前安装依赖并准备环境。

### 2. 任务发送给代理

你的任务标题和描述会被发送给代理。你会看到这是启动工作的初始消息。

### 3. 实时操作

代理工作时，每个操作都会实时显示：

- **推理过程**：代理分析你的任务时的思考过程
- **命令**：正在执行的 Shell 命令
- **文件操作**：正在创建、修改或删除的文件
- **工具使用**：API 调用、搜索和其他工具调用
- **响应**：代理消息和状态更新

**可展开的操作**：点击文件更改操作可以展开查看文件具体修改了哪些部分。

### 4. 操作审批

<Note>
目前审批功能支持 Codex，Claude Code 即将支持。
</Note>

当代理采取需要人工审批的操作时，操作下方会出现一行带有批准/拒绝按钮的提示。

<Frame>
<img src="/images/vk-approval.png" alt="审批提示，显示勾号和叉号按钮用于批准或拒绝代理操作" />
</Frame>

点击勾号批准或点击叉号拒绝操作。代理将根据你的决定继续执行或进行调整。

### 5. Cleanup 脚本

在每次代理回合结束后，你的 cleanup 脚本会运行（如果已配置）。这对于运行代码检查工具、格式化工具或其他执行后任务非常有用。

### 6. 提交消息

Vibe Kanban 根据代理发送的最后一条消息生成提交消息。这些自动生成的消息可能不总是最准确的描述。

<Tip>
合并到基础分支时，使用 GitHub 的"squash & merge"选项可以用实际更改的摘要重写提交信息。或者，你可以让编程代理手动清理提交记录。
</Tip>

## 执行过程中的交互

### 键盘快捷键

- **Cmd/Ctrl + Enter**：向代理发送消息
- **Enter**：在消息输入框中创建新行
- **Shift + Tab**：切换代理配置（如从 PLAN 切换到 DEFAULT）

### 查看任务详情

点击左上角的任务标题可以导航到任务视图。

<Frame>
<img src="/images/vk-task-title.png" alt="左上角的任务标题，点击可查看完整的任务详情" />
</Frame>

这可以让你：
- 查看完整的任务描述
- 编辑任务标题或描述
- 查看所有任务尝试

### 编辑之前的消息

<Note>
消息编辑功能支持 Claude Code、Amp、Codex、Gemini 和 Qwen。
</Note>

<Frame>
<img src="/images/vk-edit-message.png" alt="编辑之前的消息，显示保存或取消更改的选项" />
</Frame>

当你的编程代理支持时，你可以编辑对话中的之前的消息。这将把代理的工作回滚到该时间点，并使用你编辑后的消息重新执行对话。

<Warning>
编辑消息会回滚之后所有的代理工作。当你需要纠正或澄清之前的指令时，请谨慎使用此功能。
</Warning>

## 查看进程

点击右上角的三点图标并选择 **View Processes** 可以查看所有正在运行和已完成的进程。

<Frame>
<img src="/images/vk-processes-dropdown.png" alt="进程下拉菜单，显示编程代理和开发服务器进程" />
</Frame>

这里显示：
- 编程代理会话
- 开发服务器
- 构建脚本
- 其他正在运行的进程

每个进程显示其状态和执行时间线。点击任何进程可以查看其特定的输出日志。

<Tip>
对于开发服务器日志，推荐的查看方式是通过[测试你的应用](/core-features/testing-your-application)，在那里你可以同时查看日志和实时预览。
</Tip>

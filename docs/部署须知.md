# Vibe Kanban 部署须知

## 项目架构

项目包含前端 + Go 后端：

| 组件 | 说明 | 路径 |
|------|------|------|
| 本地 App 前端 | React + Vite，处理本地仓库/工作区 | `packages/local-web/` |
| Go 后端 | Chi 路由，SQLite 数据库，处理本地文件/仓库/工作区 | `cmd/server/`、`internal/` |

---

## 一、前置条件

- Node.js 20+、pnpm
- Go 1.24+
- GitHub OAuth App（或自托管本地账号）

---

## 二、启动本地 App

不需要 Docker，可直接启动：

```bash
pnpm i
pnpm run dev
```

前端默认 `http://localhost:3000`。此模式下：
- 无登录功能（`VK_SHARED_API_BASE` 未设置）
- 可直接进入看板使用
- 仓库选择、工作区创建等本地功能正常

---

## 三、Docker 部署

### 3.1 环境变量

在项目根目录创建 `.env`：

```env
# 可选
DOMAIN=localhost:8080
```

### 3.2 国内网络适配

如果你在中国大陆，`deb.debian.org`、`registry.npmjs.org` 可能不可达。Dockerfile 已做以下适配：

- **APT** → 阿里云镜像 `mirrors.aliyun.com`
- **npm/pnpm** → npmmirror 镜像 `registry.npmmirror.com`
- **Go 模块** → 使用默认 GOPROXY 或设置 `GOPROXY=https://goproxy.cn,direct`

如遇网络问题，检查 Clash 代理是否正常运行（不需要 TUN 模式，系统代理即可）。

### 3.3 端口

默认服务器端口通过 `PORT` 环境变量配置（默认自动分配）。

### 3.4 启动命令

```bash
docker build -t vibe-kanban .
docker run -p 8080:8080 -e PORT=8080 vibe-kanban
```

### 3.5 验证

```bash
curl http://localhost:8080/api/sessions
# 应返回 JSON 响应
```

## 四、常见问题

### 4.1 Docker apt-get 返回 502

`deb.debian.org` 被墙。Dockerfile 已使用阿里云镜像，如需更换：

```dockerfile
# 修改 Dockerfile 中的这行
RUN sed -i 's|http://deb.debian.org/debian|http://mirrors.aliyun.com/debian|g' ...
```

### 4.2 pnpm install 失败 (ECONNRESET)

`registry.npmjs.org` 被墙。Dockerfile 已使用 npmmirror。如需更换：

```dockerfile
ENV npm_config_registry=https://registry.npmmirror.com
```

### 4.3 Go 模块下载失败

设置 GOPROXY：

```bash
export GOPROXY=https://goproxy.cn,direct
```

### 4.4 Docker Compose 版本过老

如使用 docker-compose.yml，确保 Docker Compose 版本 >= v2.17。

### 4.5 "Project functionality has been retired"

这是上游仓库的 sunset 提交导致。本项目提交 `5ee4367b2` 已回滚此变更，恢复正常看板功能。

## 外观

自定义应用程序的外观和风格：

- **主题** - 在浅色和深色配色方案之间选择
- **语言** - 选择你的首选语言（Browser Default 会跟随系统语言）

## 默认编程 Agent

<Frame>
<img src="/images/settings-default-coding-agent.png" alt="Default Coding Agent section showing agent and variant dropdowns" />
</Frame>

设置创建新任务尝试或后续操作时默认使用的编程 Agent。

- **Agent** - 选择你的首选编程 Agent（如 Claude Code、Gemini CLI、Codex）。这决定了哪个 AI 助手来处理你的编程任务。
- **变体** - 为所选 Agent 选择一个配置变体（如 Default、Opus、Approvals）。变体包含不同的设置，如规划模式、模型选择或权限级别。

所选的 Agent 和变体会预选在创建尝试对话框中，为你启动新任务时节省时间。

<Tip>
你可以在创建尝试对话框中按尝试覆盖默认 Agent 配置。默认设置只是为你最常见的工作流提供便利。
</Tip>

## 编辑器

<Frame>
<img src="/images/settings-editor.png" alt="Editor settings showing Editor Type dropdown and Remote SSH Host input" />
</Frame>

配置你的代码编辑体验。

### 选择编辑器

从多种支持的编辑器中选择：

- **VS Code** - 微软广受欢迎的代码编辑器
- **Cursor** - 以 AI 为原生的 VSCode 分支
- **Windsurf** - 优化协作开发的 VSCode 分支
- **Zed** - 高性能代码编辑器
- **Antigravity** - Google 的 AI 原生代码编辑器
- **Neovim**、**Emacs**、**Sublime Text** - 其他常用编辑器
- **Custom** - 使用自定义 Shell 命令

### 自定义编辑器示例

选择 **Custom** 时，你可以指定任何 Shell 命令来打开文件。该命令接收文件或目录路径作为参数。

```bash
# Example: Open with IntelliJ IDEA
idea

# Example: Open with Sublime Text (custom path)
/Applications/Sublime\ Text.app/Contents/SharedSupport/bin/subl

# Example: Open with a custom script
~/scripts/open-editor.sh
```

### 打开编辑器

<Frame>
<img src="/images/settings-open-in-ide.png" alt="Open in IDE option in the context bar" />
</Frame>

配置完成后，你可以从多个位置打开编辑器：

- **上下文栏** - 点击浮动上下文栏中的 IDE 图标来打开工作区
- **命令栏** - 按 `Cmd/Ctrl + K` 并选择 "Open in IDE"

<Tip>
上下文栏显示你已配置的 IDE 图标。更多详情请参阅[工作区界面指南](/workspaces/interface)。
</Tip>

## 远程 SSH 配置

当 Vibe Kanban 运行在远程服务器上（例如通过 Cloudflare tunnel、ngrok 访问或作为 systemctl 服务运行）时，你可以配置基于 VSCode 的编辑器通过 SSH 打开项目，而不是假定使用 localhost。

此功能适用于 **VS Code**、**Cursor** 和 **Windsurf** 编辑器。

### 何时使用远程 SSH

在以下情况下启用远程 SSH 配置：
- Vibe Kanban 运行在远程服务器上（VPS、云实例等）
- 你通过隧道或反向代理访问 Web UI
- 你的代码文件位于与浏览器不同的机器上
- 你希望本地编辑器通过 SSH 连接到远程服务器

### 配置字段

- **Remote SSH Host**（可选） - 远程服务器的主机名或 IP 地址（如 `example.com`、`192.168.1.100`、`my-server`）。必须能从本地机器通过 SSH 访问。

### 工作原理

配置远程 SSH 后，点击 "Open in Editor"（或 Cursor/Windsurf）：
1. 生成一个特殊的协议 URL，如：`vscode://vscode-remote/ssh-remote+user@host/path/to/project`
2. 在默认浏览器中打开，启动本地编辑器
3. 你的编辑器通过 SSH 连接到远程服务器
4. 在远程上下文中打开项目或任务工作树

这同时适用于项目级别和任务工作树的打开。

### 前提条件

- 本地机器与远程服务器之间已配置 SSH 访问
- 已设置 SSH 密钥或凭据（无需密码提示）
- 已安装 VSCode Remote-SSH 扩展（或 Cursor/Windsurf 的等效扩展）
- 远程服务器路径必须可通过 SSH 访问

<Tip>
先用 `ssh user@host` 测试 SSH 连接，确保无需输入密码即可正常工作。
</Tip>

## Git

<Frame>
<img src="/images/settings-git.png" alt="Git settings showing Branch Prefix and Workspace Directory fields" />
</Frame>

配置 Git 分支命名和工作区存储偏好。

### 分支前缀

为自动生成的分支名称设置前缀。创建新工作区或任务时，Vibe Kanban 会自动为你的更改创建 Git 分支。

| 前缀设置 | 示例分支名称 |
|----------------|---------------------|
| `vk` | `vk/1a2b-implement-auth` |
| `feature` | `feature/1a2b-implement-auth` |
| *（空）* | `1a2b-implement-auth` |

<Tip>
使用与团队分支规范匹配的前缀（如 `feature`、`fix` 或你的姓名首字母）。
</Tip>

### 工作区目录

指定 Vibe Kanban 存储工作区数据的位置。工作区在此路径下的 `.vibe-kanban-workspaces` 子目录中创建。

- **默认位置** - 留空使用系统默认（通常为你的主目录）
- **自定义位置** - 如果你希望工作区位于不同的驱动器或目录，请设置特定路径

<Warning>
更改工作区目录需要重启应用程序。现有工作区将保留在其原始位置。
</Warning>

## 通知

<Frame>
<img src="/images/settings-notifications.png" alt="Notifications settings showing sound effects and push notifications toggles" />
</Frame>

配置 Vibe Kanban 如何提醒你关于任务进度和状态变化。

- **音效** - 在任务完成、需要关注或遇到错误时播放音频通知。适用于同时处理多个任务或 Vibe Kanban 在后台标签页运行时。
- **推送通知** - 即使 Vibe Kanban 不在前台也能接收浏览器通知。首次启用时需要浏览器权限。

<Tip>
如果你经常运行长时间任务并希望在任务完成或需要你关注时收到提醒，请启用通知。
</Tip>

## 遥测

启用或禁用遥测数据收集以帮助改进 Vibe Kanban。

## 消息输入

选择在聊天输入框中发送消息的键盘快捷键（`Enter` 或 `⌘/Ctrl + Enter`）。

<Frame>
<img src="/images/settings-tags.png" alt="Tags section showing task tags table with tag names, content, and actions" />
</Frame>

- **Add Tag +** - 创建新标签

- **操作** - 编辑或删除现有标签

设置对话框提供了一个简洁的标签式界面，用于配置 Vibe Kanban。

## 访问设置

<Frame>
<img src="/images/settings-accessing.png" alt="Workspaces navbar showing the Settings gear icon with tooltip" />
</Frame>

- 点击工作区导航栏中的 **Settings** 图标 (<Icon icon="gear" />)
- 按 `Cmd/Ctrl + K` 并选择 **Settings**

## 设置标签页

<Frame>
<img src="/images/settings-general.png" alt="Settings dialog showing the tabbed interface with General, Projects, Repositories, Organization Settings, Agents, and MCP Servers tabs" />
</Frame>

设置对话框分为以下几个标签页：

| 标签页 | 说明 |
|-----|-------------|
| **General（通用）** | 外观、默认 Agent、编辑器、Git 和通知 |
| **Projects（项目）** | 项目级别的设置 |
| **Repositories（仓库）** | 仓库脚本（开发服务器、初始化、清理） |
| **Organization Settings（组织设置）** | 组织成员、邀请和组织设置 |
| **Remote Projects（远程项目）** | 跨组织的云端同步项目 |
| **Agents（智能体）** | Agent 配置文件和变体 |
| **MCP Servers（MCP 服务器）** | Model Context Protocol 服务器配置 |

## Agents（智能体）

<Frame>
<img src="/images/settings-agents.png" alt="Agents tab showing agent list, configuration variants, and settings options" />
</Frame>

通过表单界面定义和自定义 Agent 变体。Agents 标签页采用 Finder 风格的双栏布局：

- **左栏（Agents）** - 可用的编程 Agent（Claude Code、Codex、Opencode、Cursor Agent 等）
- **右栏（Configurations）** - 所选 Agent 的不同配置变体（Default、Opus、Approvals、Plan 等）

<Card title="Agent 配置文件与变体" icon="robot" href="/settings/agent-configurations">
  配置 Agent 变体的详细指南和示例
</Card>

## MCP Servers（MCP 服务器）

<Frame>
<img src="/images/settings-mcp.png" alt="MCP Servers tab showing agent selection, JSON configuration, and popular servers" />
</Frame>

配置 Model Context Protocol 服务器，通过自定义工具和资源扩展编程 Agent 的能力。

- **Agent** - 选择要配置 MCP 服务器的 Agent（如 Claude Code）
- **Server Configuration (JSON)** - 以 JSON 格式直接编辑 MCP 服务器配置
- **Popular servers** - 点击卡片将预配置的 MCP 服务器插入到 JSON 中

<Card title="连接 MCP 服务器" icon="server" href="/settings/mcp-servers">
  在 Vibe Kanban 中为你的编程 Agent 配置 MCP 服务器
</Card>

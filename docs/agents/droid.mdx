<Steps>
<Step title="安装 Droid CLI">
  <Tabs>
  <Tab title="macOS / Linux">
  ```bash
  curl -fsSL https://app.factory.ai/cli | sh
  ```
  </Tab>

  <Tab title="Windows">
  ```powershell
  irm https://app.factory.ai/cli/windows | iex
  ```
  </Tab>
  </Tabs>

  如需最新的安装说明和平台特定指南，请访问 [Factory AI CLI 文档](https://factory.ai/product/cli)。
</Step>

<Step title="通过 Factory AI 进行身份验证">
  要在 Vibe Kanban 中使用 Droid，你需要先完成身份验证：

  1. 运行 `droid` 启动交互式 CLI
  2. 在 Droid 中使用 `/login` 命令进行身份验证

  或者，你可以从 [Factory 设置页面](https://app.factory.ai/settings/api-keys)生成 API 密钥，并将其设置为环境变量：

  ```bash
  export FACTORY_API_KEY=fk-...
  ```

  详细的身份验证说明请参阅 [Factory AI 文档](https://docs.factory.ai/factory-cli/getting-started/overview)。
</Step>

<Step title="启动 Vibe Kanban">
  完成身份验证后，启动 Vibe Kanban：

  ```bash
  npx vibe-kanban
  ```

  现在你可以在创建任务尝试时选择 Factory Droid。
</Step>
</Steps>

## 配置选项

Droid 在 Vibe Kanban 中支持以下配置选项：

- **自主级别**：控制文件和系统操作的权限级别
  - `normal`：只读模式——适合在不执行的情况下审查计划变更
  - `low`：基本的文件创建/编辑，同时阻止系统更改
  - `medium`：具有可恢复副作用的开发操作
  - `high`：具有安全隐患或重大副作用的操作
  - `skip-permissions-unsafe`：跳过所有权限检查（仅在隔离环境中使用）（默认值）

- **模型**：指定要使用的模型

- **推理强度**：控制推理深度
  - `off`：最少的推理
  - `low`：轻度推理
  - `medium`：平衡推理
  - `high`：针对复杂任务的深度推理

这些选项可以在 Vibe Kanban 中创建 agent 配置时进行设置。

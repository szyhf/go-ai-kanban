This guide covers deploying Vibe Kanban on any Linux server using Docker. This approach works with any cloud provider (AWS, DigitalOcean, Hetzner, etc.) or on-premises server.

## Prerequisites

- A Linux server with:
  - **Docker** installed
  - **2GB RAM** minimum (4GB recommended)
  - **5GB disk space**
- A **domain name** pointing to your server (optional, for remote access)

## Step 1: Build the Docker Image

Clone the Vibe Kanban repository and build:

```bash
git clone https://github.com/BloopAI/vibe-kanban.git
cd vibe-kanban
docker build -t vibe-kanban .
```

## Step 2: Run the Container

```bash
docker run -d \
  --name vibe-kanban \
  -p 8080:8080 \
  -e PORT=8080 \
  -e HOST=0.0.0.0 \
  vibe-kanban
```

Open `http://your-server:8080` in your browser to access Vibe Kanban.

<Warning>
By default, the server binds to `0.0.0.0` and is accessible from any host. Use a reverse proxy with authentication for production deployments.
</Warning>

## Step 3: Configure Reverse Proxy (Recommended)

For production, use a reverse proxy like Caddy or nginx for HTTPS:

### Using Caddy

Create a `Caddyfile`:

```text Caddyfile
your-domain.com {
    reverse_proxy vibe-kanban:8080
}
```

Then update the Docker run command to include the container in the Caddy network and set `VK_ALLOWED_ORIGINS`:

```bash
docker run -d \
  --name vibe-kanban \
  --network caddy \
  -e PORT=8080 \
  -e HOST=0.0.0.0 \
  -e VK_ALLOWED_ORIGINS=https://your-domain.com \
  vibe-kanban
```

## Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `PORT` | `0` (auto) | Server port |
| `HOST` | `127.0.0.1` | Server host address |
| `VK_ALLOWED_ORIGINS` | (none) | Comma-separated allowed origins for API requests |

## Updating

To update to a new version:

```bash
cd vibe-kanban
git pull origin main
docker build -t vibe-kanban .
docker stop vibe-kanban && docker rm vibe-kanban
docker run -d \
  --name vibe-kanban \
  -p 8080:8080 \
  -e PORT=8080 \
  -e HOST=0.0.0.0 \
  vibe-kanban
```

## Monitoring

### View Logs

```bash
docker logs -f vibe-kanban
```

### Check Health

```bash
docker ps
curl http://localhost:8080/api/sessions
```

## Troubleshooting

<AccordionGroup>
<Accordion title="SSL certificate issues">
If using Caddy, it automatically obtains SSL certificates from Let's Encrypt. Ensure:
- Your domain's DNS is correctly pointing to your server
- Ports 80 and 443 are open in your firewall
</Accordion>

<Accordion title="API requests return 403">
Set the `VK_ALLOWED_ORIGINS` environment variable to your frontend URL:
```bash
VK_ALLOWED_ORIGINS=https://your-domain.com
```
</Accordion>

<Accordion title="Out of memory during build">
If the build fails with memory errors, add swap:
```bash
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
```
</Accordion>
</AccordionGroup>

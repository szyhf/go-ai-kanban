命令栏是导航和控制工作空间的中心枢纽。无需离开键盘即可快速访问每个操作。

## 打开命令栏

| 平台 | 快捷键 |
|------|--------|
| **Mac** | `Cmd + K` |
| **Windows/Linux** | `Ctrl + K` |

你也可以点击导航栏中的命令栏图标。

## 可用命令

### 快速操作

从命令栏根页面访问这些操作：

| 命令 | 描述 |
|------|------|
| 新建工作空间 | 创建一个新的工作空间 |
| 在 IDE 中打开 | 在配置的编辑器中打开工作空间 |
| 复制路径 | 将工作空间路径复制到剪贴板 |
| 切换开发服务器 | 启动或停止开发服务器 |
| 在旧界面中打开 | 切换到经典看板界面 |
| 反馈 | 发送关于工作空间的反馈 |
| 工作空间指南 | 打开新手引导 |
| 设置 | 打开应用设置 |

### 工作空间操作

管理当前工作空间：

| 命令 | 描述 |
|------|------|
| 开始审查 | 开始代码审查会话 |
| 重命名工作空间 | 更改工作空间名称 |
| 复制工作空间 | 创建工作空间的副本 |
| 固定/取消固定工作空间 | 切换固定状态 |
| 归档/取消归档 | 移入/移出归档 |
| 删除工作空间 | 永久删除工作空间 |
| 运行设置脚本 | 执行仓库设置脚本 |
| 运行清理脚本 | 执行仓库清理脚本 |

### Git 操作

执行 Git 操作：

| 命令 | 描述 |
|------|------|
| 创建 Pull Request | 打开 PR 创建对话框 |
| 合并 | 将目标分支的变更拉取到你的工作分支 |
| 变基 | 将你的工作分支变基到目标分支上 |
| 更改目标分支 | 切换合并目标 |
| 推送 | 推送提交到远程仓库（适用时） |

<Tip>
Git 命令是上下文感知的，只在适用于当前工作空间状态时才会出现。
</Tip>

### 视图选项

控制面板可见性：

| 命令 | 描述 |
|------|------|
| 切换左侧边栏 | 显示/隐藏工作空间列表 |
| 切换聊天面板 | 显示/隐藏对话 |
| 切换右侧边栏 | 显示/隐藏详情 |
| 切换变更面板 | 显示/隐藏代码变更 |
| 切换日志面板 | 显示/隐藏进程日志 |
| 切换预览面板 | 显示/隐藏浏览器预览 |

### Diff 选项

自定义 Diff 查看器（变更面板可见时可用）：

| 命令 | 描述 |
|------|------|
| 切换 Diff 视图模式 | 在统一视图和并排视图之间切换 |
| 切换自动换行 | 启用/禁用行换行 |
| 切换忽略空白 | 显示/隐藏空白变更 |
| 展开所有 Diff | 展开所有折叠的 Diff |
| 折叠所有 Diff | 折叠所有展开的 Diff |

### 仓库操作

对于包含多个仓库的工作空间，管理各个仓库：

| 命令 | 描述 |
|------|------|
| 复制仓库路径 | 复制特定仓库的路径 |
| 在 IDE 中打开仓库 | 仅打开该仓库 |
| 仓库设置 | 配置仓库选项 |
| 创建 PR（仓库） | 为特定仓库创建 PR |
| 合并（仓库） | 合并特定仓库 |
| 变基（仓库） | 变基特定仓库 |
| 更改目标分支（仓库） | 更改特定仓库的目标 |

## 键盘快捷键

### 全局快捷键

| 快捷键 | 操作 |
|--------|------|
| `Cmd/Ctrl + K` | 打开命令栏 |
| `Escape` | 关闭命令栏或对话框 |

## 命令栏导航

命令栏将命令组织到页面中：

1. **根页面** - 快速操作和导航到其他页面
2. **工作空间操作** - 工作空间管理命令
3. **Git 操作** - 版本控制操作
4. **视图选项** - 面板可见性切换
5. **Diff 选项** - Diff 查看器设置
6. **仓库操作** - 每个仓库的命令（多仓库工作空间）

使用搜索字段在所有页面中筛选命令，或导航到特定页面进行分类访问。

<Info>
开始输入以搜索任何命令。命令栏使用模糊匹配，你不需要输入确切的命令名称。
</Info>

## 高级用户技巧

<AccordionGroup>
<Accordion title="最值得记住的命令">
这些命令将大大加快你的工作流程：

| 快捷键 | 功能 |
|--------|------|
| `Cmd/Ctrl + K` → `n` → Enter | 新建工作空间 |
| `Cmd/Ctrl + K` → `pr` → Enter | 创建 Pull Request |
| `Cmd/Ctrl + K` → `changes` → Enter | 切换变更面板 |
| `Cmd/Ctrl + K` → `preview` → Enter | 切换预览面板 |
| `Cmd/Ctrl + K` → `ide` → Enter | 在 IDE 中打开 |
</Accordion>

<Accordion title="模糊搜索技巧">
命令栏使用模糊匹配 - 你可以输入部分单词或缩写：

- `nw` 匹配"**N**ew **W**orkspace"
- `cpr` 匹配"**C**reate **P**ull **R**equest"
- `tog prev` 匹配"**Tog**gle **Prev**iew Panel"
- `reb` 匹配"**Reb**ase"
</Accordion>

<Accordion title="快速面板切换">
使用命令栏快速显示/隐藏面板，无需移动鼠标：

1. 按 `Cmd/Ctrl + K`
2. 输入 `toggle`
3. 查看所有切换选项
4. 选择你想要显示/隐藏的面板
</Accordion>

<Accordion title="上下文感知命令">
某些命令只在相关时出现：

- **推送**只在有未推送的提交时显示
- **变基**只在你落后于目标时显示
- **仓库操作**只在多仓库工作空间中显示
- **Diff 选项**只在变更面板可见时显示
</Accordion>
</AccordionGroup>

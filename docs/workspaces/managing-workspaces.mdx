了解如何组织你的工作空间列表、释放磁盘空间，以及了解归档或删除工作空间时代码会发生什么。

<Note>
**工作空间操作**可通过命令栏和工作空间侧边栏访问。这些操作需要有活跃的工作空间 - 它们不会在创建工作空间页面出现。
</Note>

## 访问工作空间操作

你可以通过两种方式访问工作空间操作：

**从侧边栏：**

<Frame>
<img style={{maxHeight: "300px"}} src="/images/workspaces-sidebar-actions.png" alt="工作空间侧边栏悬停时显示更多操作按钮" />
</Frame>

将鼠标悬停在侧边栏中的工作空间上，点击 **...**（更多操作）按钮查看可用操作。

**从命令栏：**
1. 按 `Cmd/Ctrl + K`
2. 进入**工作空间操作**
3. 选择你想要的操作

<Frame>
<img style={{maxHeight: "400px"}} src="/images/workspaces-actions-menu.png" alt="工作空间操作菜单显示可用操作，如重命名、复制、固定、归档和删除" />
</Frame>

## 固定工作空间

通过从工作空间操作中选择**固定工作空间**，将重要工作空间保持在列表顶部。

固定的工作空间会显示在侧边栏顶部，无论其最后活动时间如何。

## 归档工作空间

当你完成一个工作空间但可能稍后想返回时，将其归档以保持工作空间列表整洁。

从工作空间操作中选择**归档**，或点击导航栏左上角的**归档**按钮（<Icon icon="box-archive" />）。

归档的工作空间可以通过点击侧边栏底部的**查看归档**来查看。

<Info>
**归档会保留所有内容。** 你的对话历史、会话、笔记和 worktree 文件都保持完整。你可以随时取消归档继续工作。
</Info>

## 删除工作空间

要永久删除工作空间，从工作空间操作中选择**删除工作空间**。

<Warning>
删除工作空间是永久性的且无法撤销。在删除前确保你已推送了想要保留的任何变更。
</Warning>

### 删除内容

当你删除工作空间时：

| 内容 | 是否删除 | 说明 |
|------|----------|------|
| **工作空间数据** | 是 | 对话历史、会话、笔记 |
| **Git worktree** | 是 | 工作目录及其文件 |
| **Git 分支** | 否 | 分支保留在你的仓库中 |
| **提交** | 否 | 所有提交保留在仓库中 |
| **原始仓库** | 否 | 你的源仓库永远不会被触碰 |

<Info>
**你的代码是安全的。** 删除工作空间只会移除 worktree 副本，但所有提交保留在你的原始仓库中。如果你已推送到远程或创建了 PR，你的工作会保留。
</Info>

### 归档与删除

| 操作 | Worktree | 对话 | 能否恢复？ |
|------|----------|------|------------|
| **归档** | 保留在磁盘上 | 保留 | 可以 - 随时取消归档 |
| **删除** | 移除 | 删除 | 不可以 - 永久性的 |

**使用归档当：**
- 你可能稍后返回这项工作
- 你想保留对话历史
- 你在清理工作空间列表但任务还未完成

**使用删除当：**
- 任务已完成并合并
- 你想释放磁盘空间
- 你不需要对话历史

## 磁盘空间和 Worktree 位置

每个工作空间创建一个 **Git worktree** - 一个包含仓库跟踪文件完整副本的独立工作目录。大型仓库的多个工作空间可能会消耗大量磁盘空间。

### Worktree 存储位置

Worktree 默认存储在平台特定的目录中：

| 平台 | 默认位置 |
|------|----------|
| **macOS** | `/var/folders/.../T/vibe-kanban/worktrees`（系统临时目录） |
| **Linux** | `/var/tmp/vibe-kanban/worktrees` |
| **Windows** | `%TEMP%\vibe-kanban\worktrees` |

你可以在**设置 → 通用 → 工作空间目录**中配置自定义位置。设置后，worktree 存储在 `{你的路径}/.vibe-kanban-workspaces` 中。

### 检查磁盘使用量

<Tabs>
<Tab title="macOS">
```bash
du -sh $TMPDIR/vibe-kanban/worktrees
```
</Tab>
<Tab title="Linux">
```bash
du -sh /var/tmp/vibe-kanban/worktrees
```
</Tab>
<Tab title="Windows">
```powershell
Get-ChildItem "$env:TEMP\vibe-kanban\worktrees" -Recurse | Measure-Object -Property Length -Sum
```
</Tab>
</Tabs>

### 释放空间

要减少磁盘使用量：

1. **删除已完成的工作空间** - 对已完成并合并的任务使用删除（而非归档）
2. **检查归档的工作空间** - 归档的工作空间仍然消耗磁盘空间
3. **配置清理脚本** - 添加清理脚本以在工作空间关闭时移除构建产物（如 `node_modules`）

<Tip>
像 `node_modules`、`target/` 或 `build/` 这样的大型目录会被复制到每个 worktree 中。考虑添加清理脚本，在工作空间使用完毕后移除这些目录。
</Tip>

## 手动删除 Worktree

如果你手动删除 worktree 目录（例如在终端中使用 `rm -rf`），Vibe Kanban 会在你下次打开该工作空间时**自动重新创建**它。Worktree 从分支的最后一次提交重新创建。

<Warning>
**未提交的变更将丢失。** 如果你有已暂存或未暂存的未提交变更，它们无法恢复。在手动删除 worktree 目录之前始终提交你的工作。
</Warning>

## 孤立 Worktree 清理

Vibe Kanban 会在启动时自动清理"孤立"的 worktree - 这些是不再有数据库中匹配工作空间的 worktree 目录（例如应用在删除过程中崩溃）。

此清理自动运行，你不需要手动管理过期的 worktree 目录。

## 重命名工作空间

要重命名工作空间，从工作空间操作中选择**重命名工作空间**并输入新名称。

## 复制工作空间

要创建现有工作空间的副本，从工作空间操作中选择**复制工作空间**。

副本包含相同的仓库和分支配置，但以全新的对话开始。

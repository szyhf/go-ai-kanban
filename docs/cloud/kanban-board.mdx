看板是你管理工作的主视图。事项被组织到代表工作流不同阶段的列中，你可以随着工作进展拖放它们。

<Frame>
  <img src="/images/cloud/project-kanban-board.png" alt="Kanban board showing columns with issue cards" />
</Frame>

## 看板布局

看板由以下部分组成：

- **筛选栏** - 搜索、筛选和排序事项（顶部）
- **状态列** - 代表工作流阶段的垂直列
- **事项卡片** - 列中的单项工作
- **列标题** - 显示带颜色指示器的状态名称

### 状态列

每列代表工作流中的一个状态。默认情况下，项目有六个状态：

| 列 | 用途 |
|--------|---------|
| **To do** | 准备开始 |
| **In progress** | 正在进行 |
| **In review** | 等待代码审查 |
| **Done** | 已完成 |

另外两个状态默认隐藏：**Backlog**（用于想法和未来工作）和 **Cancelled**（用于不会完成的事项）。你可以通过看板上方的状态标签页访问它们。

你可以[自定义这些列](/cloud/customisation)——添加新的、重命名、更改颜色，或隐藏/显示你需要的列。

### 事项卡片

每张卡片一览显示关键信息：

- **Simple ID** - 事项标识符（例如 ISS-1）
- **Title** - 需要完成什么
- **Priority** - 颜色编码的指示器（如果已设置）
- **Assignees** - 已分配团队成员的头像
- **Tags** - 彩色标签（如果有）

点击任意卡片打开完整的[事项面板](/cloud/issues)。

## 拖放

使用拖放在列之间移动事项以及在列内重新排序。

<Frame>
  <img src="/images/cloud/drag-drop.png" alt="Dragging an issue card between columns" />
</Frame>

### 在列之间移动

要更改事项的状态：

1. 点击并按住事项卡片
2. 将其拖到目标列
3. 松开鼠标放下


事项的状态会立即更新，所有团队成员都能实时看到更改。

### 在列内重新排序

要更改列内事项的顺序：

1. 确保你处于 **Manual** 排序模式（检查筛选栏中的排序下拉菜单）
2. 点击并按住事项卡片
3. 在同一列内向上或向下拖动
4. 松开鼠标放到新位置

<Info>
重新排序仅在排序模式为 **Manual** 时有效。如果你按 Priority、Created 或其他字段排序，顺序是自动确定的，你无法拖动重新排序。
</Info>

### 拖动指示器

拖动时，你会看到视觉反馈：

- **光标变化** - 显示你处于拖动模式
- **放置目标** - 高亮显示卡片将放置的位置
- **卡片阴影** - 显示正在移动的卡片

## 状态标签页

看板上方，标签页让你在不同视图之间切换：

<Frame>
  <img src="/images/cloud/status-tabs.png" alt="Status tabs showing Active, All, Backlog, and Cancelled" />
</Frame>

| 标签 | 视图 | 显示内容 |
|-----|------|-------|
| **Active** | 看板 | 可见状态的看板列 |
| **All** | [列表视图](/cloud/list-view) | 包括隐藏状态在内的所有事项 |
| **Backlog**、**Cancelled** 等 | [列表视图](/cloud/list-view) | 特定隐藏状态中的事项 |

<Info>
隐藏状态标签页（如 Backlog 或 Cancelled）仅在你于[显示设置](/cloud/customisation)中隐藏了这些状态时才会出现。这对于保持看板整洁同时仍能快速访问已归档或待办事项非常有用。
</Info>

## 多选

选择多个事项卡片以直接在看板上执行批量操作。

### 如何选择

- **Cmd/Ctrl + Click** 卡片以切换其选中状态
- **Shift + Click** 卡片以选择从上次选中卡片到当前卡片之间的范围
- **X** 切换当前打开事项的选中状态
- **Shift + J / ↓** 或 **Shift + K / ↑** 向下或向上扩展选择一个事项
- **Cmd/Ctrl + A** 选择所有可见事项
- **Escape** 清除选择

被选中的卡片会用强调色环高亮显示。选择事项时，拖放功能会被禁用以防止误操作。

当选择两个或更多事项时，屏幕底部会出现一个**批量操作栏**。你可以一次性更改所有选中事项的状态、优先级或负责人，或删除它们。完整详情请参见[选择多个事项](/cloud/issues#selecting-multiple-issues)。

## 使用看板

### 打开事项

点击任意事项卡片在屏幕右侧打开事项面板。面板显示完整详情并允许你编辑事项。

### 快速更改状态

无需打开事项，你可以通过将其拖到其他列来更改状态。这是批量更新事项的最快方式。

### 键盘快捷键

| 快捷键 | 操作 |
|----------|--------|
| `X` | 切换当前事项选中状态 |
| `Shift + J / ↓` | 向下扩展选择 |
| `Shift + K / ↑` | 向上扩展选择 |
| `Cmd/Ctrl + A` | 选择所有事项 |
| `Escape` | 清除选择 / 关闭事项面板 |
| `Cmd/Ctrl + K` | 打开命令栏执行快捷操作 |

## 实时协作

看板会随着团队成员的更改而实时更新：

- **事项移动** - 卡片动画移动到新位置
- **事项创建** - 新卡片自动出现
- **事项更新** - 标题、优先级等更改即时显示
- **事项删除** - 卡片从看板消失

你无需刷新页面——一切自动同步。

<Info>
如果你和队友同时移动同一个事项，以最后的操作为准。看板会在两个操作完成后显示最终位置。
</Info>

## 空列

没有事项的列显示空状态。你可以：

- 将事项拖入空列
- 使用 **+** 按钮在该列中创建新事项
- 如果你不需要该列显示在看板上，在[显示设置](/cloud/customisation)中[隐藏该状态](/cloud/customisation)

## 最佳实践

</CardGroup>

## 故障排除

<AccordionGroup>
<Accordion title="无法在列内重新排序事项">
确保你处于 **Manual** 排序模式。点击筛选栏中的排序下拉菜单并选择"Manual"。如果你按 Priority、Created 或其他字段排序，顺序是固定的。
</Accordion>

<Accordion title="事项不显示">
检查你的筛选器——可能存在活跃的筛选器隐藏了一些事项。点击筛选栏中的 **Clear All** 重置筛选并查看所有事项。
</Accordion>

<Accordion title="某列不见了">
该列可能被隐藏了。前往[显示设置](/cloud/customisation)检查该状态是否设为隐藏。将其切换回可见。
</Accordion>

<Accordion title="更改未保存">
检查你的网络连接。看板需要活跃的连接来同步更改。如果你离线，更改在重新连接之前不会保存。
</Accordion>
</AccordionGroup>

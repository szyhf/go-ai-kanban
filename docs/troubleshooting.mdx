## 编码代理报告代码库为空

如果在创建新任务时，你的编码代理报告代码库为空，可能是因为你的仓库启用了 Git 的 sparse-checkout（稀疏检出）功能。

**解决方案：**

在仓库的根目录下运行以下命令：

```bash
git sparse-checkout disable
```

禁用 sparse-checkout 后，重新创建任务并重试。

## 启用调试日志

如果你需要更详细的日志来帮助排查问题，可以通过设置 `VK_LOG_LEVEL` 环境变量来启用 debug 级别的日志。

**使用方法：**

```bash
VK_LOG_LEVEL=debug npx vibe-kanban
```

这将提供详细的日志输出，帮助你定位问题的根本原因。

## 危险操作：清除数据库

如果你遇到无法恢复的错误，需要彻底清除 Vibe Kanban 数据库，可以根据你的操作系统删除应用程序数据目录。

<Warning>
此操作不可逆，将导致所有任务和设置的丢失。请在操作前务必备份重要信息。
</Warning>

**根据你的操作系统删除以下目录：**

<Tabs>
<Tab title="macOS">
```bash
~/Library/Application Support/ai.bloop.vibe-kanban/
```
</Tab>

<Tab title="Linux">
```bash
~/.local/share/vibe-kanban/
```
</Tab>

<Tab title="Windows">
```
%APPDATA%\bloop\vibe-kanban\
```

通常位于：`C:\Users\<username>\AppData\Roaming\bloop\vibe-kanban\`
</Tab>
</Tabs>

删除应用程序数据目录后，重新启动 Vibe Kanban，将以空数据库和默认设置重新初始化。

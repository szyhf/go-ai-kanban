## 什么是标签？

标签是可复用的文本片段，你可以通过输入 `@` 后跟标签名称快速插入到工作区提示中。选择标签后，其内容会自动插入到光标位置。

<Tip>
标签使用 snake_case 命名（不允许使用空格）。例如：`bug_report`、`feature_request` 或 `code_review_checklist`。
</Tip>

## 管理标签

从 **Settings → General → Tags** 访问标签。标签在工作区的所有项目中全局可用。

<Frame>
<img src="/images/settings-tags.png" alt="Tags management interface showing the tag list with names and content" />
</Frame>

<Steps>
<Step title="创建新标签">
  点击 **Add Tag** 创建新标签。

  <Frame>
  <img src="/images/settings-create-task-tag.png" alt="Create tag dialogue showing tag name and content fields" />
  </Frame>

  - **标签名称**：使用 snake_case，不含空格（如 `acceptance_criteria`）
  - **内容**：使用标签时将插入的文本
</Step>

<Step title="编辑现有标签">
  点击标签旁边的编辑图标（✏️）以修改其名称或内容。
</Step>

<Step title="删除不需要的标签">
  点击删除图标（🗑️）删除不再需要的标签。

  <Warning>
  删除标签不会影响已插入标签内容的现有任务。
  </Warning>
</Step>
</Steps>

## 使用标签

通过 @提及自动补全将标签插入到工作区提示和后续消息中。

<Steps>
<Step title="触发自动补全">
  编写提示时，输入 `@` 触发自动补全下拉菜单。

  <Frame>
  <img src="/images/settings-task-tag-autocomplete.png" alt="Autocomplete dropdown showing available tags after typing @ symbol" />
  </Frame>
</Step>

<Step title="搜索并选择">
  继续输入以按名称筛选标签，然后：
  - 点击标签进行选择
  - 使用方向键导航并按 Enter 选择
  - 按 Escape 关闭下拉菜单

  <Check>
  标签的内容会自动插入到光标位置，替换 @查询文本。
  </Check>
</Step>
</Steps>

## 常见用例

<AccordionGroup>
<Accordion title="Bug 报告模板">
创建一个 `bug_report` 标签，包含标准化的 Bug 报告字段：

```
**Description:**

**Steps to reproduce:**
1.
2.
3.

**Expected behaviour:**

**Actual behaviour:**

**Environment:**
```
</Accordion>

<Accordion title="验收标准清单">
创建一个 `acceptance_criteria` 标签，用于功能需求：

```
**Acceptance criteria:**
- [ ] Functionality works as specified
- [ ] Unit tests added
- [ ] Documentation updated
- [ ] Accessibility requirements met
- [ ] Performance benchmarks passed
```
</Accordion>

<Accordion title="代码审查指南">
创建一个 `code_review` 标签，包含审查清单项目：

```
**Code review checklist:**
- [ ] Code follows project conventions
- [ ] Tests cover edge cases
- [ ] No security vulnerabilities introduced
- [ ] Performance impact assessed
- [ ] Documentation is clear
```
</Accordion>
</AccordionGroup>

<Tip>
标签在所有支持 @提及功能的文本字段中均可使用，包括工作区提示和后续消息，便于在任务中保持一致性。
</Tip>

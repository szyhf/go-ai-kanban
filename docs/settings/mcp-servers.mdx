<Note>
本页面介绍如何在 Vibe Kanban **内部**为你的编程 Agent 配置 MCP 服务器。关于将外部 MCP 客户端连接到 Vibe Kanban 的 MCP 服务器，请参阅 [Vibe Kanban MCP 服务器](/integrations/vibe-kanban-mcp-server)指南。
</Note>

## 概述

MCP 服务器通过标准化协议为编程 Agent 提供额外功能。你可以在 Vibe Kanban 中为每个编程 Agent 配置不同的 MCP 服务器，使其能够访问专业工具，如浏览器自动化、远程日志访问、通过 Sentry 进行错误跟踪或从 Notion 获取文档。

## 访问 MCP 服务器配置

1. 在工作区导航栏中点击 **Settings**
2. 点击 **MCP Servers** 标签页
3. 选择你要配置 MCP 服务器的编程 Agent

## 添加自定义 MCP 服务器

你也可以通过手动配置来添加自己的 MCP 服务器：

<Steps>
<Step title="选择编程 Agent">
从 Agent 下拉菜单中选择你要配置 MCP 服务器的编程 Agent。
</Step>

<Step title="更新服务器配置 JSON">
在 Server Configuration JSON 编辑器中，添加你的自定义 MCP 服务器配置。JSON 会显示所选 Agent 的当前配置，你可以修改它以包含额外的服务器。

示例添加：
```json
{
  "mcpServers": {
    "existing_server": {
      "command": "npx",
      "args": ["-y", "some-existing-server"]
    },
    "my_custom_server": {
      "command": "node",
      "args": ["/path/to/my-server.js"]
    }
  }
}
```
</Step>

<Step title="保存并测试">
更新 JSON 配置后：

1. 点击 "Save Settings" 应用更改
2. 通过使用具有 MCP 功能的 Agent 来测试配置
3. 查看 Agent 日志以了解连接问题

<Check>
这些更改会更新编程 Agent 的全局配置文件，即使你停止使用 Vibe Kanban 也会保留。
</Check>
</Step>
</Steps>

## 最佳实践

<Tip>
**服务器选择**：选择与你的编程 Agent 主要功能互补的 MCP 服务器。例如，如果 Agent 专注于 Web 开发，请使用 Playwright。
</Tip>

<Tip>
**限制 MCP 服务器数量**：避免向单个编程 Agent 添加过多 MCP 服务器。过多的服务器和工具会通过大量选项使编程 Agent 不堪重负，从而降低其效果。
</Tip>

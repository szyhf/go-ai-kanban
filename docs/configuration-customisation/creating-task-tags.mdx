## 什么是任务标签？

任务标签是可复用的文本片段，你可以通过输入 `@` 后跟标签名称来快速将其插入到任务描述中。当你选择一个标签时，其内容会自动插入到光标位置。

<Tip>
任务标签使用 snake_case 命名（不允许包含空格）。例如：`bug_report`、`feature_request` 或 `code_review_checklist`。
</Tip>

## 管理任务标签

从 **Settings → General → Task Tags** 访问任务标签。标签在工作区的所有项目中全局可用。

<Frame>
<img src="/images/screenshot-task-tags-manager.png" alt="任务标签管理界面，显示标签列表及其名称和内容" />
</Frame>

<Steps>
<Step title="创建新标签">
  点击 **Add Tag** 创建新的任务标签。

  <Frame>
  <img src="/images/screenshot-create-task-tag.png" alt="创建任务标签对话框，显示标签名称和内容字段" />
  </Frame>

  - **标签名称**：使用 snake_case 格式，不含空格（例如 `acceptance_criteria`）
  - **内容**：使用标签时将插入的文本
</Step>

<Step title="编辑现有标签">
  点击标签旁边的编辑图标（✏️）来修改其名称或内容。
</Step>

<Step title="删除不需要的标签">
  点击删除图标（🗑️）来移除不再需要的标签。

  <Warning>
  删除标签不会影响已经插入该标签内容的现有任务。
  </Warning>
</Step>
</Steps>

## 使用任务标签

通过 @提及 自动补全功能将任务标签插入到任务描述和后续跟进消息中。

<Steps>
<Step title="触发自动补全">
  在创建或编辑任务描述时，输入 `@` 以触发自动补全下拉菜单。

  <Frame>
  <img src="/images/screenshot-task-tag-autocomplete.png" alt="输入 @ 符号后显示可用标签的自动补全下拉菜单" />
  </Frame>
</Step>

<Step title="搜索并选择">
  继续输入以按名称过滤标签，然后：
  - 点击标签以选择
  - 使用方向键导航并按 Enter 选择
  - 按 Escape 关闭下拉菜单

  <Check>
  标签内容会自动插入到光标位置，替换 @查询文本。
  </Check>
</Step>
</Steps>

## 常见用例

<AccordionGroup>
<Accordion title="Bug 报告模板">
创建一个 `bug_report` 标签，包含标准化的 Bug 报告字段：

```
**Description:**

**Steps to reproduce:**
1. 
2. 
3. 

**Expected behaviour:**

**Actual behaviour:**

**Environment:**
```
</Accordion>

<Accordion title="验收标准清单">
创建一个 `acceptance_criteria` 标签，用于功能需求：

```
**Acceptance criteria:**
- [ ] Functionality works as specified
- [ ] Unit tests added
- [ ] Documentation updated
- [ ] Accessibility requirements met
- [ ] Performance benchmarks passed
```
</Accordion>

<Accordion title="代码审查指南">
创建一个 `code_review` 标签，包含审查清单项目：

```
**Code review checklist:**
- [ ] Code follows project conventions
- [ ] Tests cover edge cases
- [ ] No security vulnerabilities introduced
- [ ] Performance impact assessed
- [ ] Documentation is clear
```
</Accordion>
</AccordionGroup>

<Tip>
任务标签适用于所有支持 @提及 功能的文本字段，包括任务描述和后续跟进消息，让你可以轻松保持任务间的一致性。
</Tip>

Vibe Kanban Cloud 让你与团队实时协作。你的数据同步到云端，每个人都能看到相同的项目、事项和更新。

<Info>
**已经在使用本地版 Vibe Kanban？** Cloud 使用你熟悉的相同界面。区别在于你的数据会同步到云端，并且你可以邀请团队成员。
</Info>

## 第 1 步：启动 Vibe Kanban

如果你还没有启动，运行以下命令：

```bash
npx vibe-kanban
```

应用将在浏览器中打开，地址为 `http://localhost:...`。

## 第 2 步：登录

要使用 Cloud 功能，你需要先登录。

<Steps>
<Step title="点击登录">
  点击侧边栏中的 **Login** 按钮或在出现提示时点击。
</Step>

<Step title="选择登录方式">
  选择你想要的登录方式：
  - **Sign in with GitHub** - 使用你的 GitHub 账户
  - **Sign in with Google** - 使用你的 Google 账户

  <Frame>
    <img src="/images/cloud/sign-in-dialog.png" alt="Sign in dialog with GitHub and Google options" />
  </Frame>
</Step>

<Step title="授权应用">
  你将被重定向到 GitHub 或 Google。如需请先登录，然后点击 **Authorize** 或 **Allow** 授予 Vibe Kanban 访问权限。

  <Info>
  Vibe Kanban 仅请求访问你的基本资料（姓名、邮箱、头像）。它无法访问你的私有仓库或以你的名义发布内容。
  </Info>
</Step>

<Step title="返回 Vibe Kanban">
  授权完成后，你将自动跳转回 Vibe Kanban 并完成登录。
</Step>
</Steps>

## 第 3 步：你的个人组织

首次登录时，系统会自动为你创建一个**个人组织**，以及一个**初始项目**帮助你开始。这是你的私有工作空间。

<Info>
个人组织仅供你个人使用——你无法邀请其他成员。要与团队协作，请创建新组织（参见第 5 步）。
</Info>

## 第 4 步：创建你的第一个项目

现在创建一个项目来组织你的工作。

<Steps>
<Step title="点击新建项目">
  点击侧边栏中的 **+ New Project** 按钮。
</Step>

<Step title="输入项目详情">
  - **Name** - 你的工作内容（例如"Mobile App"、"Website Redesign"）
  - **Colour** - 选择一个颜色来标识项目

  <Frame>
    <img style={{maxHeight: "300px"}} src="/images/cloud/create-project-dialog.png" alt="Create Project dialog with name and colour fields" />
  </Frame>
</Step>

<Step title="点击创建">
  你的项目已创建，看板已准备就绪。

  <Frame>
    <img src="/images/cloud/project-kanban-board.png" alt="Project kanban board with default columns" />
  </Frame>
</Step>
</Steps>

## 第 5 步：邀请团队成员（可选）

创建团队组织来与他人协作，然后邀请你需要的成员。团队组织和成员邀请免费，但新的付费订阅已关闭。

<Steps>
<Step title="邀请团队成员">
  打开组织设置（点击组织名称旁边的齿轮图标），然后：
  - 点击 **Invite Member**
  - 输入队友的邮箱地址
  - 选择角色（**Member** 或 **Admin**）
  - 点击 **Send Invitation**

  <Frame>
    <img style={{maxHeight: "300px"}} src="/images/cloud/invite-member-dialog.png" alt="Invite Member dialog" />
  </Frame>
</Step>
</Steps>

他们将收到包含加入链接的邮件。

## 准备就绪！

你现在拥有：
- ✅ 一个 Cloud 账户
- ✅ 一个团队组织
- ✅ 一个带有看板的项目

**下一步：**
- [创建事项](/cloud/issues)来跟踪你的工作
- [了解看板](/cloud/kanban-board)来管理任务
- [自定义看板](/cloud/customisation)配置列和标签
- [邀请更多团队成员](/cloud/team-members)来协作

## 退出登录

退出登录的步骤：
1. 点击左侧边栏底部的**头像图标**
2. 点击 **Sign out**

<Frame>
  <img style={{maxHeight: "350px"}} src="/images/cloud/user-menu.png" alt="User menu showing Sign out option" />
</Frame>

你的数据安全地保存在云端。随时可以重新登录继续工作。

## 在本地和 Cloud 之间切换

你可以同时使用本地项目和 Cloud 项目：

| 本地项目 | Cloud 项目 |
|----------------|----------------|
| 数据存储在你的电脑上 | 数据同步到云端 |
| 仅你个人可访问 | 团队成员可协作 |
| 无需登录 | 需要登录 |
| 可离线使用 | 需要网络连接 |

两者都在同一个 Vibe Kanban 界面中显示。本地项目显示在一个区域，Cloud 项目显示在另一个区域。

## 故障排除

<AccordionGroup>
<Accordion title="无法登录">
**可能的原因：**
- 弹出窗口拦截器阻止了 OAuth 窗口
- 网络连接问题

**解决方案：**
1. 为 localhost 禁用弹出窗口拦截器
2. 检查网络连接
3. 尝试使用其他浏览器
</Accordion>

<Accordion title="看不到 Cloud 功能">
**可能的原因：**
- 你尚未登录

**解决方案：**
1. 点击侧边栏中的 **Login**
2. 完成登录流程
</Accordion>

<Accordion title="我的队友看不到我们的项目">
**可能的原因：**
- 他们尚未接受邀请
- 他们使用了不同的邮箱登录

**解决方案：**
1. 在成员设置中检查邀请是否仍在待处理状态
2. 重新发送邀请
3. 确认他们使用的是你邀请的邮箱地址
</Accordion>
</AccordionGroup>

---
title: "键盘快捷键"
description: "Workspaces UI 中可用的键盘快捷键"
---

Workspaces UI 通过 **Keyboard Shortcuts** 对话框提供全面的键盘导航功能。

## 访问键盘快捷键

| 快捷键 | 操作 |
|----------|------|
| `⌘/Ctrl + /` | 打开键盘快捷键对话框 |

<Info>
组合快捷键需要先按第一个键，然后在 500 毫秒内按第二个键。
</Info>

## 快捷操作

| 快捷键 | 操作 |
|----------|------|
| `?` | 显示键盘快捷键帮助 |
| `Esc` | 关闭/取消 |
| `C` | 创建新任务 |
| `D` | 删除选中项 |
| `/` | 聚焦搜索框 |

## 修饰键

| 快捷键 | 操作 |
|----------|------|
| `⌘/Ctrl + K` | 打开命令栏 |
| `⌘/Ctrl + E` | 格式化行内代码 |
| `⌘/Ctrl + Enter` | 发送消息 |

## 导航

| 快捷键 | 操作 |
|----------|------|
| `J` | 向下移动 |
| `K` | 向上移动 |
| `H` | 向左移动 |
| `L` | 向右移动 |

## Issue 选择

这些快捷键在 Kanban 看板和列表视图中可用。

| 快捷键 | 操作 |
|----------|------|
| `X` | 切换当前 Issue 的选中状态 |
| `Shift + J` / `Shift + ↓` | 向下扩展选择 |
| `Shift + K` / `Shift + ↑` | 向上扩展选择 |
| `⌘/Ctrl + A` | 选择所有可见的 Issue |
| `Esc` | 清除选择 |

## 跳转 (G ...)

| 快捷键 | 操作 |
|----------|------|
| `G S` | 跳转到 Settings |
| `G N` | 跳转到 New Workspace |

## Workspace (W ...)

| 快捷键 | 操作 |
|----------|------|
| `W D` | 复制 Workspace |
| `W R` | 重命名 Workspace |
| `W P` | 固定/取消固定 Workspace |
| `W A` | 归档 Workspace |
| `W X` | 删除 Workspace |

## 视图 (V ...)

| 快捷键 | 操作 |
|----------|------|
| `V C` | 切换 Changes 面板 |
| `V L` | 切换 Logs 面板 |
| `V P` | 切换 Preview 面板 |
| `V S` | 切换左侧边栏 |
| `V H` | 切换 Chat 面板 |

## Git (X ...)

这些快捷键在 Workspace 内部可用。

| 快捷键 | 操作 |
|----------|------|
| `X P` | 创建 Pull Request |
| `X M` | 合并分支 |
| `X R` | 变基分支 |
| `X U` | 推送更改 |

## 复制 (Y ...)

这些快捷键在 Workspace 内部可用。

| 快捷键 | 操作 |
|----------|------|
| `Y P` | 复制路径 |
| `Y L` | 复制原始日志 |

## 切换 (T ...)

这些快捷键在 Workspace 内部可用。

| 快捷键 | 操作 |
|----------|------|
| `T D` | 切换开发服务器 |
| `T W` | 切换自动换行 |

## 运行 (R ...)

这些快捷键在 Workspace 内部可用。

| 快捷键 | 操作 |
|----------|------|
| `R S` | 运行 setup 脚本 |
| `R C` | 运行 cleanup 脚本 |

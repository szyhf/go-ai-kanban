工作空间是你与编码 Agent 协作的任务执行环境。每个工作空间可以包含一个或多个仓库，并支持多个对话会话。

## 创建工作空间时发生了什么

了解幕后发生的事情有助于你更有效地工作：

<Steps>
<Step title="创建 Git worktree">
Vibe Kanban 创建一个 **Git worktree** - 一个拥有自己分支的独立工作目录。这使你的变更与主代码库隔离。你的原始仓库保持不变。
</Step>

<Step title="创建工作分支">
基于你的目标分支（例如 `main`）创建一个新分支。分支名称根据你的任务自动生成（例如 `vk/abc123-add-login-page`）。
</Step>

<Step title="启动 Agent 会话">
编码 Agent 被初始化并准备接收你的指令。Agent 可以在工作空间内读取文件、进行更改和运行命令。
</Step>

<Step title="运行设置脚本（如已配置）">
如果你的仓库配置了设置脚本（例如 `npm install`），它们会自动运行以准备环境。
</Step>
</Steps>

<Info>
**工作空间存放在哪里？** Worktree 创建在 `.vibe-kanban-workspaces` 目录中（可在设置 → 通用 → 工作空间目录中配置）。每个工作空间都有自己的文件夹。
</Info>

## 创建新工作空间

<Steps>
<Step title="打开创建视图">
  点击工作空间侧边栏顶部的 **+** 按钮，或使用命令栏（`Cmd/Ctrl + K`）并选择**新建工作空间**。

  <Frame>
  <img style={{maxHeight: "300px"}} src="/images/workspaces-sidebar-create-button.png" alt="工作空间侧边栏显示用于创建新工作空间的加号按钮" />
  </Frame>
</Step>

<Step title="选择项目">
  从右侧面板的**项目**下拉菜单中选择一个项目。项目将相关仓库分组在一起。

  <Frame>
  <img style={{maxHeight: "300px"}} src="/images/workspaces-select-project.png" alt="项目下拉菜单显示已选中的项目" />
  </Frame>

  <Note>
  如果你还没有创建项目，请参阅下面的[创建新项目](#creating-a-new-project)。
  </Note>
</Step>

<Step title="添加仓库">
  <Frame>
  <img style={{maxHeight: "350px"}} src="/images/workspaces-add-repo.png" alt="仓库选择显示已选仓库和分支下拉菜单以及可用仓库列表" />
  </Frame>

  选择要包含在工作空间中的仓库：

  - **最近仓库** - 点击列表中的任何仓库来添加
  - **浏览磁盘上的仓库** - 查找不在最近列表中的仓库
  - **在磁盘上创建新仓库** - 初始化一个新的 Git 仓库

  <Tip>
  如果你的任务涉及多个代码库，你可以在单个工作空间中添加多个仓库。每个仓库维护独立的 Git 状态。
  </Tip>
</Step>

<Step title="设置目标分支">
  对于每个选定的仓库，设置**目标分支** - 这是你的变更最终要合并到的分支（例如 `main` 或 `develop`）。

  点击每个仓库旁边的分支下拉菜单来更改目标分支。

  <Info>
  **目标分支与工作分支有什么区别？**

  - **目标分支** = 你的变更最终要合并到的地方（例如 `main`）。由你设置。
  - **工作分支** = 你进行变更的地方（例如 `vk/abc123-task-name`）。从目标分支自动创建。

  你的变更在工作分支上进行，在你创建并合并 PR 之前不会影响目标分支。
  </Info>
</Step>

<Step title="描述你的任务">
  在底部的聊天输入中，描述你想要完成的事情。具体说明：

  - 你需要什么功能或修复
  - 任何约束或要求
  - 要关注的文件或代码库区域

  <Tip>
  清晰、详细的任务描述有助于 Agent 理解你的需求并产生更好的结果。
  </Tip>
</Step>

<Step title="选择 Agent">
  从 **Agent** 下拉菜单中选择要使用的编码 Agent。可用的 Agent 取决于你的配置。

  <Note>
  有关设置不同 Agent 的详情，请参阅 [Agent 配置](/settings/agent-configurations)。
  </Note>
</Step>

<Step title="创建工作空间">
  点击**创建**启动工作空间。Agent 将立即开始处理你的任务。
</Step>
</Steps>

## 创建新项目

如果你需要在设置工作空间之前创建新项目：

<Steps>
<Step title="打开项目下拉菜单">
  在创建工作空间视图中，点击**项目**下拉菜单。

  <Frame>
  <img style={{maxHeight: "300px"}} src="/images/workspaces-project-dropdown.png" alt="项目下拉菜单显示创建新项目选项和现有项目列表" />
  </Frame>
</Step>

<Step title="选择创建新项目">
  点击下拉列表顶部的 **+ 创建新项目**。
</Step>

<Step title="输入项目详情">
  <Frame>
  <img style={{maxHeight: "250px"}} src="/images/workspaces-create-project.png" alt="创建项目对话框包含名称字段" />
  </Frame>

  输入项目名称并点击**创建**。
</Step>

<Step title="继续创建工作空间">
  你的新项目会被自动选中。继续添加仓库并配置你的工作空间。
</Step>
</Steps>

<Note>
创建项目后，你可以在项目设置中配置额外的设置，如设置脚本、开发服务器脚本和清理脚本。详见[项目与仓库](/settings/projects-repositories)。
</Note>

## 工作空间设置

工作空间创建后，你可以配置额外的设置：

### 工作分支

工作空间会自动为你的变更创建一个工作分支。你可以在详情侧边栏的 **Git** 部分查看和更改此分支。

### 开发服务器

如果你的项目配置了开发服务器脚本，可以通过以下方式启动：
- 上下文栏中的**播放**图标（<Icon icon="play" />）
- 命令栏：`Cmd/Ctrl + K` → **启动开发服务器**

<Note>
在项目设置中配置开发服务器脚本。详见[项目与仓库](/settings/projects-repositories)获取设置说明。
</Note>

### 工作空间笔记

使用详情侧边栏中的**笔记**部分来记录关于工作空间的重要信息 - 需求、决策或任何你想记住的内容。

## 复制工作空间

要创建现有工作空间的副本：

1. 打开命令栏（`Cmd/Ctrl + K`）
2. 进入**工作空间操作**
3. 选择**复制工作空间**

副本包含相同的仓库和分支配置，但以全新的对话开始。

## 归档工作空间

当你完成一个工作空间后，将其归档以保持工作空间列表整洁：

**从导航栏：**
- 点击导航栏左上角的**归档**按钮（<Icon icon="box-archive" />）

**从命令栏：**
1. 按 `Cmd/Ctrl + K`
2. 进入**工作空间操作** → **归档**

归档的工作空间可以通过点击侧边栏底部的**查看归档**来查看。

<Tip>
使用**固定**功能将重要的活跃工作空间保持在列表顶部。
</Tip>

## 故障排除

<AccordionGroup>
<Accordion title="我在列表中看不到我的仓库">
**可能的原因：**
- 仓库尚未添加到项目中
- 文件夹不是 Git 仓库（没有 `.git` 文件夹）
- 路径无法访问

**解决方案：**
1. 点击**浏览磁盘上的仓库**手动定位仓库
2. 确保文件夹包含 `.git` 目录
3. 检查 Vibe Kanban 是否有权限访问该文件夹
</Accordion>

<Accordion title="工作空间创建失败">
**可能的原因：**
- Git worktree 创建失败（通常由于原始仓库中有未提交的变更）
- 分支名称冲突
- 磁盘空间不足

**解决方案：**
1. 提交或暂存原始仓库中的任何未提交变更
2. 尝试不同的目标分支
3. 检查可用磁盘空间（worktree 需要跟踪文件的完整副本的空间）
</Accordion>

<Accordion title="创建工作空间后 Agent 不启动">
**可能的原因：**
- Agent 未安装或未配置
- API Key 问题
- 网络连接问题

**解决方案：**
1. 检查你的 Agent（例如 Claude Code）是否已安装：在终端中手动运行 CLI 命令
2. 验证 API Key 已在设置 → Agent 中配置
3. 检查你的网络连接
</Accordion>

<Accordion title="设置脚本失败">
**可能的原因：**
- 脚本有错误
- 缺少依赖项
- 工作目录不正确

**解决方案：**
1. 首先在终端中手动测试脚本
2. 检查日志面板中的错误消息
3. 确保脚本中的路径相对于仓库根目录
</Accordion>
</AccordionGroup>

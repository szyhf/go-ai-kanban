## 安装

<Tabs>
<Tab title="VSCode">
直接从 Visual Studio Code Marketplace 安装：

<Card title="VSCode Marketplace" icon="download" href="https://marketplace.visualstudio.com/items?itemName=bloop.vibe-kanban">
  安装适用于 VSCode 的官方 Vibe Kanban 扩展
</Card>

或者，在 VSCode 中通过扩展 ID 搜索：
1. 打开 VSCode
2. 按 `Ctrl+Shift+X`（Windows/Linux）或 `Cmd+Shift+X`（macOS）打开扩展面板
3. 搜索 `@id:bloop.vibe-kanban`
4. 点击 **Install**
</Tab>

<Tab title="Cursor">
对于 Cursor，使用 Open VSX Registry：

<Card title="Open VSX Registry" icon="download" href="https://open-vsx.org/extension/bloop/vibe-kanban">
  从 Open VSX 安装以确保 Cursor 兼容性
</Card>

<Tip>
由于从 Open VSX 的深度链接在 Cursor 中不太可靠，最简单的安装方法是在 IDE 中通过扩展 ID 搜索。
</Tip>

**安装步骤**：
1. 打开 Cursor
2. 打开扩展面板
3. 搜索 `@id:bloop.vibe-kanban`
4. 安装扩展
</Tab>

## 功能

扩展提供了一个集成的工作区视图，包含三个主要组件：

### 日志视图
- 当前任务的任务尝试列表
- 每个任务尝试中执行的智能体步骤

### 差异对比视图
- 代码更改的并排比较
- 行内评论和审查功能

### 进程视图
- 监控运行中的任务进程
- 进程状态指示器（运行中、已完成、失败）

### 任务管理
- **任务迭代**：继续迭代当前进行中的任务
- **状态更新**：实时任务状态同步

## 使用工作流

<Steps>
<Step title="在 Vibe Kanban 中启动任务">
  导航到你的项目看板，创建或选择一个现有任务。
</Step>

<Step title="打开任务">
  点击任务以打开其详细视图。
</Step>

<Step title="启动 IDE 集成">
  根据你首选的 IDE，点击 **"Open in VSCode"**、**"Open in Cursor"** 或 **"Open in Windsurf"** 按钮。
  
  <Note>
  按钮文字将反映你在 Vibe Kanban 设置中配置的编辑器选择。
  </Note>
</Step>

<Step title="在 IDE 中工作">
  你的 IDE 将在任务专用的工作树中打开，扩展 UI 将显示以下内容：
  - 当前任务上下文
  - 实时日志
  - 代码差异
  - 进程监控
</Step>
</Steps>

## 故障排除

### 扩展 UI 为空

**问题**：扩展 UI 显示为空或没有显示任务信息。

**解决方案**：确保你正在 Vibe Kanban 任务创建的工作树中工作。

<Warning>
只有当 VSCode 打开的目录对应于一个活跃的 Vibe Kanban 任务工作树时，扩展才能显示任务信息。
</Warning>

**解决步骤**：
1. 确认你是通过 Vibe Kanban 任务中的"Open in [IDE]"按钮打开的 VSCode
2. 检查你是否在正确的目录/工作树中
3. 如果问题仍然存在，重启 IDE 并重试工作流

### 扩展未加载

**问题**：Vibe Kanban 扩展未出现在你的 IDE 中。

**解决方案**：
- 在扩展中搜索 `@id:bloop.vibe-kanban` 以确认扩展已安装
- 安装后重启 IDE
- 检查你使用的是兼容的 IDE 版本
- 对于 Cursor/Windsurf 用户，确保从 Open VSX Registry 安装

## 最佳实践

<Tip>
**工作流优化**：始终先从 Vibe Kanban Web 界面启动任务，然后再在 IDE 中打开，以确保正确的上下文和工作树设置。
</Tip>

<Tip>
**性能**：关闭不使用的 IDE 窗口以减少资源占用。
</Tip>

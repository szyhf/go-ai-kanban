<Steps>
<Step title="运行 GitHub Copilot">
  ```bash
  npx -y @github/copilot
  ```
</Step>

<Step title="按照登录指引操作">
  按照提示，使用 `/login` 命令完成身份验证。更多详情请参阅 [GitHub Copilot CLI 文档](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/use-copilot-cli)。
</Step>

<Step title="启动 Vibe Kanban">
  完成身份验证后，启动 Vibe Kanban：

  ```bash
  npx vibe-kanban
  ```

  现在你可以在创建任务尝试时选择 GitHub Copilot。
</Step>
</Steps>

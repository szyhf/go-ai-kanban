事项是你项目中的单项工作——需要修复的 Bug、要开发的功能、要完成的任务。每个事项存在于你的看板上，可以分配给团队成员、打标签、设置优先级，并在工作流程中跟踪。

<Frame>
  <img src="/images/cloud/issue-overview.png" alt="Kanban board with New Issue panel showing issue creation form" />
</Frame>

## 什么是事项？

一个**事项**代表一单项工作。它包含：

- **Title** - 对需要完成内容的简要描述
- **Description** - 详细信息、需求或上下文
- **Status** - 它所在的列（To Do、In Progress、Done 等）
- **Priority** - 紧急程度（Urgent、High、Medium、Low）
- **Assignees** - 负责这项工作的人员
- **Tags** - 用于分类和筛选的标签
- **Simple ID** - 类似 `TASK-123` 的唯一标识符，方便引用


## 创建事项

### 从列中创建

要在特定列中创建事项：

1. 点击任意状态列顶部的 **+** 按钮
2. 新事项面板打开，该状态已预选
3. 填写事项详情并点击 **Create Task**

<Frame>
  <img src="/images/cloud/column-add-button.png" alt="Column header showing the + button to create a new issue" />
</Frame>

### 从标题栏创建

使用标题栏按钮创建事项：

<Frame>
  <img src="/images/cloud/header-add-button.png" alt="Header showing the + button next to status tabs for creating a new issue" />
</Frame>

<Steps>
<Step title="打开创建面板">
  点击状态标签旁边的 **+** 按钮。
</Step>

<Step title="输入标题">
  输入一个清晰、描述性的标题。标题字段会自动获取焦点。
</Step>

<Step title="设置状态">
  选择事项应该开始的列。
</Step>

<Step title="设置优先级（可选）">
  选择优先级（默认为无优先级）：

  | 优先级 | 使用场景 |
  |----------|-------------|
  | **Urgent** | 需要立即关注，正在阻塞其他工作 |
  | **High** | 重要，应尽快完成 |
  | **Medium** | 普通优先级 |
  | **Low** | 锦上添花，可以等待 |
</Step>

<Step title="分配团队成员（可选）">
  点击负责人字段并选择一个或多个团队成员。你可以为同一个事项分配多个人。
</Step>

<Step title="添加标签（可选）">
  选择标签来分类事项。标签有助于筛选和组织。
</Step>

<Step title="添加描述（可选）">
  使用富文本编辑器编写详细描述。你可以格式化文本、添加列表、代码块和链接。
</Step>

<Step title="创建事项">
  点击 **Create Task** 保存事项。事项将出现在所选状态列的看板上。
</Step>
</Steps>

### 创建时附带 Workspace

如果你想立即在 AI 辅助下开始处理一个事项：

<Frame>
  <img style={{maxHeight: "400px"}} src="/images/cloud/issue-create-form.png" alt="New Issue panel showing Create draft workspace immediately toggle" />
</Frame>

1. 创建事项时，启用 **Create draft workspace immediately**
2. 事项创建时会关联一个 [workspace](/workspaces/index)
3. 你可以立即开始使用编码代理工作

查看 [Workspaces](/workspaces/index) 了解更多关于编码代理工作的信息。

## 编辑事项

### 打开事项

点击看板上的任意事项卡片打开事项面板。面板从右侧滑入。


### 自动保存

标题和描述的更改会**自动保存**。你无需点击保存按钮——只需编辑，更改即会保存。

<Info>
自动保存有短暂延迟（约半秒），以避免保存每次按键。如果你在输入后立即关闭面板，请稍等片刻让保存完成。
</Info>

### 编辑属性

状态、优先级、负责人和标签等属性的更改会**立即保存**：

| 属性 | 编辑方式 |
|----------|-------------|
| **Status** | 点击状态下拉菜单选择新状态，或将卡片拖动到其他列 |
| **Priority** | 点击优先级下拉菜单选择级别 |
| **Assignees** | 点击负责人字段，选择/取消选择团队成员 |
| **Tags** | 点击标签字段，选择/取消选择标签 |

### 编辑描述

描述使用富文本编辑器，支持以下格式：

- **粗体**、*斜体*、~~删除线~~
- 项目列表和编号列表
- 用于技术内容的代码块
- 外部资源链接


## 事项分区

事项面板包含可折叠的分区以显示附加信息：

### Workspace 分区

显示与此事项关联的开发 workspace。[Workspace](/workspaces/index) 是编码代理工作的地方。

<Frame>
  <img style={{maxHeight: "150px"}} src="/images/cloud/workspaces-section.png" alt="Workspaces section showing a linked active workspace" />
</Frame>

每个关联的 workspace 显示：
- **Status** - Active、idle 或 completed
- **Age** - 创建距今的时间
- **PR status** - 是否已创建 Pull Request

**关联 workspace：**

点击 Workspace 分区标题中的 **+** 按钮创建新 workspace 或关联已有的。

<Frame>
  <img style={{maxHeight: "300px"}} src="/images/cloud/link-workspace-dropdown.png" alt="Link workspace dropdown showing Create new workspace and existing workspaces" />
</Frame>

**取消关联 workspace：**

点击 workspace 上的 **...** 菜单并选择 **Unlink from issue**。

<Frame>
  <img style={{maxHeight: "200px"}} src="/images/cloud/workspace-menu-unlink.png" alt="Workspace menu showing Unlink from issue and Delete workspace options" />
</Frame>

### 子事项分区

事项可以有子事项（子任务）用于分解工作：

<Frame>
  <img style={{maxHeight: "120px"}} src="/images/cloud/sub-issues-section.png" alt="Sub-issues section showing No sub-issues message with add button" />
</Frame>

- **Add Sub-Issue** - 创建新的子事项
- **Link Existing Issue** - 将已有事项设为子任务
- **View Parent** - 如果这是子事项，查看其父事项

### 评论分区

事项的讨论区：


- **Add Comment** - 分享更新、提问或提供反馈
- **React** - 对评论添加表情反应
- **Edit/Delete** - 修改或删除你自己的评论

## 子事项（子任务）

使用子事项将大型事项拆分为更小、可管理的部分。

### 创建子事项

<Steps>
<Step title="打开父事项">
  点击将作为父事项的事项。
</Step>

<Step title="展开子事项分区">
  点击 **Sub-Issues** 分区标题展开。
</Step>

<Step title="点击添加子事项">
  点击子事项分区标题中的 **+** 按钮。会出现一个下拉菜单，提供创建新事项或关联已有事项的选项。

  <Frame>
    <img style={{maxHeight: "250px"}} src="/images/cloud/add-sub-issue-dropdown.png" alt="Add Sub-issue dropdown showing Create new issue and existing issues to link" />
  </Frame>
</Step>

<Step title="创建或关联">
  - 点击 **Create new issue** 创建新的子事项
  - 或从列表中选择已有事项将其关联为子事项
</Step>
</Steps>

### 查看父事项

查看子事项时，你会在事项属性下方看到一个 **Parent** 链接。点击它导航到父事项。

<Frame>
  <img style={{maxHeight: "250px"}} src="/images/cloud/sub-issue-parent-link.png" alt="Sub-issue showing Parent: ISS-1 link to navigate to parent issue" />
</Frame>

### 子事项行为

- 子事项和普通事项一样显示在看板上
- 它们可以有自己的状态、优先级和负责人
- 完成所有子事项不会自动完成父事项
- 子事项不能再有子事项（仅支持一级嵌套）

## 事项操作

事项操作提供对常用事项操作的快速访问。你可以通过两种方式访问：

### 从事项面板

点击事项面板右上角的 **More** 按钮（三个点）。

<Frame>
  <img style={{maxHeight: "150px"}} src="/images/cloud/issue-panel-more-button.png" alt="Issue panel header showing the three dots More button" />
</Frame>

### 从命令栏

使用 `Cmd/Ctrl + K` 打开命令栏，然后选择 **Issue Actions**。

<Frame>
  <img style={{maxHeight: "350px"}} src="/images/cloud/command-panel-issue-actions.png" alt="Command panel showing Issue Actions option" />
</Frame>

### 可用操作

<Frame>
  <img style={{maxHeight: "350px"}} src="/images/cloud/issue-actions-menu.png" alt="Issue Actions menu showing all available actions with keyboard shortcuts" />
</Frame>

| 操作 | 快捷键 | 说明 |
|--------|----------|-------------|
| **Create Issue** | `I C` | 创建新事项 |
| **Change Status** | `I S` | 将事项移到其他状态 |
| **Change Priority** | `I P` | 设置或更改优先级 |
| **Change Assignees** | `I A` | 添加或移除负责人 |
| **Make Sub-issue of** | `I M` | 将此事项设为另一个事项的子事项 |
| **Add Sub-issue** | `I B` | 为此事项添加子事项 |
| **Link Workspace** | `I W` | 将 workspace 关联到此事项 |
| **Duplicate Issue** | `I D` | 创建此事项的副本 |
| **Delete Issue** | - | 永久删除此事项 |

## 复制事项链接

要与某人分享事项：

1. 打开事项面板
2. 点击面板标题中的 **Copy Link** 按钮（<Icon icon="link" />）
3. 事项 URL 已复制到剪贴板

将此链接分享给团队成员——他们点击即可直接跳转到该事项。

## 选择多个事项

你可以选择多个事项来执行批量操作，类似于在文件管理器中选择文件。

### 选择方式

| 方式 | 操作 |
|--------|--------|
| **复选框** | 将鼠标悬停在列表行的左边缘显示复选框，然后点击 |
| **Cmd/Ctrl + Click** | 切换单个事项的选中状态 |
| **Shift + Click** | 选择从上次选中事项到当前点击事项之间的范围 |
| **X** | 切换当前打开事项的选中状态 |
| **Shift + J / Shift + ↓** | 向下扩展选择一个事项 |
| **Shift + K / Shift + ↑** | 向上扩展选择一个事项 |
| **Cmd/Ctrl + A** | 选择所有可见事项 |
| **Escape** | 清除选择 |

<Info>
选择功能在[看板视图](/cloud/kanban-board)和[列表视图](/cloud/list-view)中均可使用。在列表视图中，鼠标悬停时每行会出现复选框。在看板视图中，使用修饰键或键盘快捷键选择卡片。
</Info>

### 批量操作栏

当选择两个或更多事项时，屏幕底部会出现一个浮动操作栏。你可以：

| 操作 | 说明 |
|--------|-------------|
| **Status** | 一次性更改所有选中事项的状态 |
| **Priority** | 为所有选中事项设置相同的优先级 |
| **Assignee** | 为所有选中事项分配或更改负责人 |
| **Delete** | 永久删除所有选中事项 |

点击操作栏上的 **X** 按钮或按 **Escape** 清除选择。

<Warning>
批量删除是永久性操作，无法撤销。所有选中事项及其评论和历史记录都将被删除。
</Warning>

<Tip>
在选择事项之前先使用筛选器缩小范围。例如，按特定状态筛选，然后按 **Cmd/Ctrl + A** 选择所有匹配的事项进行批量状态更改。
</Tip>

## 删除事项

删除单个事项：

1. 打开事项面板
2. 点击 **More** 按钮（三个点）打开事项操作
3. 选择 **Delete Issue**
4. 确认删除

要删除多个事项，选中它们并点击批量操作栏中的 **Delete**。

<Warning>
删除事项是永久性操作。事项、其评论和历史记录将被删除。子事项不会被删除——它们会变为独立事项。
</Warning>

## 事项 Simple ID

每个事项都有一个 **Simple ID**——类似 `TASK-123` 的简短唯一标识符。这方便在对话、提交和文档中引用事项。

Simple ID 显示在：
- 看板上的事项卡片
- 事项面板标题
- 查看事项时的 URL

<Tip>
在提交消息中使用 Simple ID（例如"Fix login bug TASK-123"）来建立代码与事项之间的清晰关联。
</Tip>

## 最佳实践

<CardGroup cols={2}>
<Card title="编写清晰的标题" icon="heading">
  事项标题应描述需要完成什么，而不是问题描述。"Add password reset flow"比"Users can't reset password"更好。
</Card>

<Card title="合理使用优先级" icon="flag">
  将"Urgent"保留给真正的紧急情况。如果所有事项都是紧急的，那就等于没有紧急事项。
</Card>

<Card title="有目的地分配" icon="user">
  将事项分配给真正会处理它们的人。待办事项不分配也没关系。
</Card>

<Card title="保持描述更新" icon="file-lines">
  随着需求变化或了解更多信息，及时更新描述。它是需要完成什么内容的真实来源。
</Card>
</CardGroup>

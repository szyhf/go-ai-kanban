**最后更新：** *2026 年 2 月 28 日*

**Vibe Kanban** 非常重视平台安全和客户数据保护。我们欢迎负责任的安全漏洞报告，以帮助我们快速、安全地识别和解决问题。

## 如何报告安全问题

如果你认为自己发现了 Vibe Kanban 范围内的漏洞，请发送电子邮件至：

[**security@bloop.com**](mailto:security@bloop.com)

提交报告时，请尽可能包含以下信息：

- 漏洞的 **摘要** 及其潜在影响
- **复现步骤**（截图或清晰的描述会有帮助）
- **环境详情**（操作系统、浏览器、设备等）
- **概念验证代码** 或相关的漏洞利用详情

收到你的报告后，我们将：

1. 及时确认收到的报告。
2. 调查并对问题进行分类评估。
3. 如需澄清或重新测试，与你进行沟通。
4. 努力修复问题并随时向你更新进展。

## 漏洞披露范围

以下服务和资产目前属于负责任披露的范围：

- https://cloud.vibekanban.com（远程服务器）
- https://relay.vibekanban.com（中继服务器）

在大多数情况下，我们只奖励以下类型的漏洞：
- 任意代码执行
- SQL 注入

如果你不确定某个问题是否在范围内，请在测试前联系我们。

## 不在范围内的内容

为确保所有人的安全，并专注于真正影响用户的问题，以下内容被视为不在范围内：

- 未经事先协调的自动化扫描
- 针对 Vibe Kanban 人员的社交工程攻击
- 不会造成实质性损害的速率限制或缺失头信息问题
- 暴力破解或拒绝服务攻击
- 需要物理访问系统或拦截其他用户网络流量的攻击
- 没有实际可利用性证明的理论性漏洞

## 请不要

- 访问或修改不属于你的数据
- 破坏我们的服务或导致停机
- 在我们有机会修复之前公开分享问题的详情

## 报告格式建议

为帮助我们高效诊断问题，报告应包含：

- 清晰的 **摘要和标题**
- 受影响的 URL 或组件
- 确切的 **复现步骤**，适当时附上截图
- 环境和版本详情
- 概念验证代码或有效载荷

## 安全港与致谢

我们尊重善意行事并遵循本负责任披露政策的安全研究人员的努力。只要你遵守本政策，**Vibe Kanban 不会对负责任报告漏洞的个人采取法律行动**。

提交有效且有影响力报告的研究人员可能会获得 **致谢** 或其他酌情奖励，由 Vibe Kanban 自行决定。

## 保密条款

你作为报告的一部分与我们共享的所有信息将被严格保密。我们不会在修复之前公开披露敏感细节，如果计划进行公开致谢，我们将与你协调。

## 赏金与奖励

Vibe Kanban 可能会为符合条件的漏洞报告提供金钱奖励。

对于能证明明确影响的严重且文档完善的漏洞披露（如远程代码执行），每个漏洞我们可能支付最高 5,000 美元的奖励。

奖励由我们自行决定，取决于以下因素：

- 问题的严重程度和影响
- 报告的质量和清晰度
- 可复现性
- 漏洞是否为首次发现

并非所有报告都能获得奖励。

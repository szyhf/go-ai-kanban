在当今世界，软件工程师将大部分时间花在规划和审查编码代理的工作上，想要交付更多成果，最有效的方式就是加快规划和审查的速度。

Vibe Kanban 正是为此而生。使用看板问题来规划工作，可以私下进行，也可以与团队协作。当你准备开始时，创建工作区让编码代理执行任务。

我们不是编码代理，但能与 Claude Code、Codex、Gemini CLI 和 OpenCode 等多款主流编码代理无缝协作。

```bash
npx vibe-kanban
```

一条命令。描述工作、审查差异、交付成果。

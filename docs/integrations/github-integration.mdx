---
title: "GitHub 集成"
description: "连接 GitHub，直接从 Vibe Kanban 创建 Pull Request 并管理工作流"
---

Vibe Kanban 与 GitHub 集成，让你可以直接从任务尝试中创建 Pull Request。此集成依赖于系统上已安装并完成身份验证的 [GitHub CLI (`gh`)](https://cli.github.com/)。

## 设置

无需在 Vibe Kanban 设置中手动配置 GitHub。只要你安装了 GitHub CLI，集成即可开箱即用。

### 自动设置
当你首次尝试创建 Pull Request 时，Vibe Kanban 会检查 GitHub CLI 是否可用。如果未找到或未完成身份验证，系统将引导你完成设置过程：

1.  **在 macOS 上**：你将看到一个对话框，提供通过 Homebrew 自动安装 GitHub CLI 的选项。
2.  **在 Windows/Linux 上**：系统将提供手动安装 CLI 的说明。

### 手动设置
你也可以在使用 Vibe Kanban 之前在终端中手动设置集成：

1.  **安装 GitHub CLI**：按照适用于你操作系统的[官方安装说明](https://github.com/cli/cli#installation)进行操作。
2.  **身份验证**：在终端中运行以下命令并按照提示操作：
    ```bash
    gh auth login
    ```
    选择 **GitHub.com**，选择 **HTTPS** 或 **SSH** 作为首选协议，并通过网页浏览器完成登录。

## 创建 Pull Request

GitHub CLI 准备就绪后，你可以直接从任务中创建 Pull Request：

1.  打开一个包含你要合并更改的任务。
2.  点击 **Create PR** 按钮。
3.  将出现一个对话框，预填充以下内容：
    *   **标题**：从任务标题派生。
    *   **描述**：从任务描述派生。
    *   **目标分支**：更改的目标分支（默认为仓库的默认分支或尝试中指定的分支）。
4.  点击 **Create** 在 GitHub 上创建 PR。

如果操作成功，任务状态将更新，并提供新 Pull Request 的链接。

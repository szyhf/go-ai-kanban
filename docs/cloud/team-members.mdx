---
title: "团队成员"
description: "邀请同事并管理团队对你组织的访问"
---

通过邀请成员加入你的组织来与团队协作。成员可以查看项目、处理任务并接收实时更新。

## 邀请团队成员

只有组织 **Admin** 可以邀请新成员。

<Steps>
<Step title="前往组织设置">
  点击左侧边栏底部的**头像图标**，然后点击组织名称旁边的**齿轮图标**（<Icon icon="gear" />）。
</Step>

<Step title="点击邀请成员">
  点击右上角的 **Invite Member** 按钮。
</Step>

<Step title="输入邮箱">
  输入你想邀请的人的邮箱地址。

  <Info>
  使用他们将用来登录的邮箱（他们的 GitHub 或 Google 邮箱）。如果不确定，请询问他们哪个邮箱关联了 GitHub/Google 账户。
  </Info>
</Step>

<Step title="选择角色">
  选择他们的角色：
  - **Member** - 可以处理项目，但无法管理组织设置
  - **Admin** - 完全访问权限，包括成员管理

  <Tip>
  初始选择 **Member** 角色即可。如果需要，以后随时可以提升为 Admin。
  </Tip>
</Step>

<Step title="发送邀请">
  点击 **Send Invitation**。他们将收到一封包含加入说明的邮件。

  <Frame>
    <img src="/images/cloud/invite-member-dialog.png" alt="Invite Member dialog with email and role fields" />
  </Frame>
</Step>
</Steps>

### 邀请后会发生什么

1. 被邀请人收到包含邀请链接的邮件
2. 他们点击链接并登录（或创建账户）
3. 他们被自动添加到你的组织
4. 他们出现在你的成员列表中


<Warning>
**邀请链接 7 天后过期。** 如果被邀请人未能在期限内接受，你需要重新发送邀请。
</Warning>

## 查看待处理邀请

待处理的邀请显示在组织设置的成员列表上方。只有 Admin 可以看到待处理邀请。

每个待处理邀请显示：
- **邮箱地址** - 被邀请的人
- **过期时间** - 邀请 7 天后过期
- **撤销按钮** - 如需取消邀请

## 管理成员

### 查看成员

所有当前成员列在组织设置的 **Members** 分区中。

<Frame>
  <img src="/images/cloud/members-section.png" alt="Members section showing member list with Invite Member button" />
</Frame>

每个成员显示：
- **Name** - 他们的 GitHub/Google 显示名称和头像
- **Role** - Admin 或 Member

### 更改成员角色

要将成员提升为 Admin 或将 Admin 降级为 Member：

<Steps>
<Step title="找到成员">
  打开组织设置并在成员列表中找到该人员。
</Step>

<Step title="点击角色下拉菜单">
  点击他们当前的角色徽章打开下拉菜单。
</Step>

<Step title="选择新角色">
  选择 **Admin** 或 **Member**。更改立即生效。
</Step>
</Steps>

<Warning>
**你不能降级自己。** 如果你是唯一的管理员并想降级自己，请先提升另一个成员为管理员。
</Warning>

### 移除成员

要从组织中移除某人：

<Steps>
<Step title="找到成员">
  打开组织设置并在成员列表中找到该人员。
</Step>

<Step title="点击移除">
  点击他们名字旁边的 **Remove** 按钮。
</Step>

<Step title="确认移除">
  在提示时确认移除。
</Step>
</Steps>

<Info>
**移除某人后会发生什么：**
- 他们立即失去对组织的访问权限
- 他们无法查看任何项目或数据
- 他们过去的活动（评论、任务更新）保留，但显示他们的名字
- 如果需要，可以稍后重新邀请
</Info>

## 成员角色详解

### Admin 角色

Admin 对组织拥有完全控制权：

| 权限 | 说明 |
|------------|-------------|
| ✅ 所有项目访问 | 查看、创建、编辑所有项目 |
| ✅ 任务管理 | 创建、编辑、删除任务 |
| ✅ 邀请成员 | 向新成员发送邀请 |
| ✅ 移除成员 | 从组织中移除人员 |
| ✅ 更改角色 | 将成员提升为 Admin 或降级 |
| ✅ 组织设置 | 编辑名称、配置设置 |
| ✅ 删除组织 | 永久删除组织 |

### Member 角色

Member 可以处理项目，但无法管理组织：

| 权限 | 说明 |
|------------|-------------|
| ✅ 所有项目访问 | 查看、创建、编辑所有项目 |
| ✅ 任务管理 | 创建、编辑、删除任务 |
| ❌ 邀请成员 | 无法发送邀请 |
| ❌ 移除成员 | 无法移除人员 |
| ❌ 更改角色 | 无法更改任何人的角色 |
| ❌ 组织设置 | 无法编辑组织设置 |
| ❌ 删除组织 | 无法删除组织 |

<Info>
两种角色对**项目和任务拥有相同的访问权限**。区别仅在于组织管理权限。
</Info>

## 转移所有权

如果你需要转移组织的完全所有权（例如你要离开公司）：

<Steps>
<Step title="将新所有者提升为 Admin">
  确保接手的人拥有 Admin 角色。
</Step>

<Step title="（可选）降级自己">
  如果你继续作为普通成员，其他管理员可以降级你。
</Step>

<Step title="离开组织">
  如果你完全离开，现在可以从设置中离开组织。
</Step>
</Steps>

<Warning>
**必须始终至少有一个 Admin。** 系统不允许降级或移除最后一个管理员。
</Warning>

## 最佳实践

<CardGroup cols={2}>
<Card title="最小权限原则" icon="shield">
  默认给人们 Member 角色。仅将需要管理组织的人提升为 Admin。
</Card>

<Card title="设置多个管理员" icon="users">
  至少有两个 Admin。如果其中一个不可用，另一个仍然可以管理组织。
</Card>

<Card title="及时移除" icon="user-minus">
  当成员离开你的团队或公司时及时移除，以维护安全。
</Card>

<Card title="核实邮箱" icon="envelope">
  邀请前确认你使用的邮箱正确——即关联他们 GitHub/Google 账户的邮箱。
</Card>
</CardGroup>

## 故障排除

<AccordionGroup>
<Accordion title="被邀请人没有收到邮件">
**问题：** 你邀请的人说他们没有收到邮件。

**解决方案：**
1. 让他们检查垃圾邮件/垃圾箱
2. 确认你输入的邮箱地址正确
3. 撤销旧邀请并发送新的
4. 让他们检查是否屏蔽了你域名的邮件
</Accordion>

<Accordion title="邀请链接不工作">
**问题：** 点击邀请链接显示错误。

**可能的原因：**
- 邀请已过期（7 天后）
- 邀请已被取消
- 链接被复制不完整

**解决方案：**
从成员设置页面发送新的邀请。
</Accordion>

<Accordion title="成员看不到项目">
**问题：** 新成员说他们看不到任何项目。

**可能的原因：**
- 他们使用了与被邀请时不同的账户登录
- 同步延迟

**解决方案：**
1. 让他们刷新页面
2. 确认他们使用正确的账户登录（检查个人资料中的邮箱）
3. 检查成员列表确认他们出现在其中
</Accordion>

<Accordion title="无法邀请更多成员">
**问题：** 邀请按钮不可用或显示错误。

**可能的原因：**
- 你不是 Admin
- 所选组织是个人组织

**解决方案：**
1. 检查你的角色——只有 Admin 可以邀请
2. 确认你选择的是团队组织
</Accordion>

<Accordion title="被移除的成员仍然有访问权限">
**问题：** 你移除的人说他们仍然可以访问组织。

**可能的原因：**
- 浏览器缓存
- 他们有另一个仍然是成员的账户

**解决方案：**
1. 让他们清除浏览器缓存并刷新
2. 检查他们是否可能使用了不同的账户登录
3. 在你的成员列表中确认他们确实已被移除
</Accordion>
</AccordionGroup>

---
title: "问题管理"
description: "在看板上创建、组织和跟踪问题，从草稿到完成"
---

问题是 Vibe Kanban 中的基本工作单元。它们代表一个 bug、功能或需要完成的工作 —— 并且在你创建工作区时，它们会变成编码代理收到的提示词。本指南将带你了解问题的完整生命周期。

## 1. 创建你的第一个问题

你可以通过任何列标题上的 **+** 按钮或筛选栏中的 **新建问题** 按钮来创建问题。

<Frame>
  <img src="/images/issue-mgmt-create-button.png" alt="Kanban board showing the New Issue button in the header and the plus button on a column" />
</Frame>

使用 **团队** 和 **个人** 标签页在所有项目问题和仅分配给你的问题之间切换。

<Frame>
  <img src="/images/issue-mgmt-team-personal.png" alt="Filter bar showing the Team and Personal tabs" />
</Frame>

为你的问题起一个清晰、具体的标题，描述你期望的结果。问题面板在右侧打开，你可以在其中填写详细信息。

<Frame>
  <img src="/images/issue-mgmt-create-panel.png" alt="New issue panel with title field and description editor" />
</Frame>

## 2. 编写有效的描述

描述是你为编码代理提供上下文的地方。使用富文本编辑器来格式化你的指令，支持加粗、斜体、列表和行内代码。你还可以使用 Markdown 快捷方式来添加标题（`#`）和链接（`[文本](url)`）。

<Frame>
  <img style={{maxHeight: "300px"}} src="/images/issue-mgmt-description.png" alt="Issue description editor with formatted text including headings and code blocks" />
</Frame>

好的描述能决定编码代理是精确交付你需要的内容，还是偏离方向。

| 要素 | 弱示例 | 强示例 |
|------|--------|--------|
| **标题** | "修复 bug" | "修复慢速连接下的登录超时问题" |
| **描述** | "出问题了" | "3G 网络用户在 5 秒后看到超时。预期：使用指数退避策略进行优雅重试。" |

<Tip>
你的问题描述会成为编码代理收到的提示词。描述越具体，结果越好。
</Tip>

## 3. 设置优先级、负责人和标签

使用优先级来表示紧急程度，将问题分配给团队成员，并添加标签来对你的工作进行分类。

<Frame>
  <img src="/images/issue-mgmt-priority-tags.png" alt="Issue panel showing the priority dropdown and tags selector" />
</Frame>

| 优先级 | 使用场景 |
|--------|----------|
| **紧急** | 生产环境宕机或用户被阻塞 |
| **高** | 应该优先处理的重要工作 |
| **中** | 当前迭代周期中的标准工作 |
| **低** | 锦上添花的改进或未来想法 |

<Info>
标签是项目级别的。你可以在编辑问题时通过标签选择器来管理它们。
</Info>

## 4. 在看板上管理问题

通过拖放在列之间移动问题来更改其状态，或在同一列内拖放来重新排序。

<Frame>
  <img src="/images/issue-mgmt-kanban-board.png" alt="Kanban board showing issues being dragged between columns" />
</Frame>

| 列 | 含义 |
|----|------|
| **待办** | 尚未开始的工作 |
| **进行中** | 代理或人员正在积极处理 |
| **审查中** | 工作已完成，等待你的审查 |
| **已完成** | 已完成并验证 |

**待办** 和 **已取消** 列默认隐藏 —— 切换到 **全部** 标签页可以查看它们。

<Frame>
  <img src="/images/issue-mgmt-all-tab.png" alt="All tab selected showing Backlog and Cancelled statuses alongside the default columns" />
</Frame>

<Tip>
要在列内重新排序问题，请确保排序设置为 **手动**。其他排序模式（优先级、创建时间、更新时间）会覆盖手动排序。
</Tip>

## 5. 通过子问题拆分工作

大型功能在拆分为更小的、适合代理处理的任务时更容易管理。子问题允许你在问题之间创建父子关系。

要添加子问题，打开父问题并滚动到 **子问题** 部分。你有两个选择：点击 **+** 按钮创建新的子问题，或点击链接按钮将现有问题作为子问题关联。

<Frame>
  <img style={{maxHeight: "300px"}} src="/images/issue-mgmt-sub-issues.png" alt="Sub-issues section showing child issues with mixed statuses" />
</Frame>

子问题的关键规则：

- 每个子问题都有自己 **独立的状态** —— 完成所有子问题不会自动完成父问题
- 子问题显示 **父问题** 链接，方便你导航回父问题

## 6. 将问题连接到工作区

工作区是你的编码代理实际执行工作的地方。打开一个问题并滚动到 **工作区** 部分。你有两个选择：点击 **+** 按钮创建新的工作区，或点击链接按钮连接现有的工作区。

<Frame>
  <img style={{maxHeight: "300px"}} src="/images/issue-mgmt-link-workspace.png" alt="Issue panel showing the Workspaces section with Create and link buttons" />
</Frame>

<Info>
你可以将多个工作区连接到同一个问题 —— 这对于在同一功能的不同部分并行运行代理非常有用。
</Info>

## 故障排除

<AccordionGroup>
<Accordion title="问题没有出现在看板上">
- 检查你当前的筛选条件 —— 点击 **清除所有** 来重置
- 问题可能在 **待办** 或 **已取消** 中 —— 切换到 **全部** 标签页查看隐藏的状态
</Accordion>

<Accordion title="无法拖拽问题进行重新排序">
排序模式必须设置为 **手动**。如果排序设置为优先级、创建时间或其他模式，拖拽重新排序将被禁用。在看板头部更改排序选项。
</Accordion>

<Accordion title="描述更改没有保存">
更改会在短暂延迟后自动保存。如果更改未持久化，请检查你的网络连接，并尝试刷新页面。
</Accordion>
</AccordionGroup>

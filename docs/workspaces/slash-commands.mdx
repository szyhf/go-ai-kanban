斜杠命令是编码 Agent 中常用操作的快捷方式。输入 `/` 后跟命令名称来运行操作，如压缩对话历史、初始化项目文档或审查代码变更。

## 使用斜杠命令

使用斜杠命令：

1. 在聊天输入的新行开头输入 `/`
2. 出现自动补全菜单显示可用命令
3. 继续输入以筛选列表，或使用方向键导航
4. 按 **Enter** 或点击选择命令
5. 在命令名称后添加任何参数（某些命令接受可选参数）
6. 像平常一样发送消息

<Tip>
某些命令接受可选参数。例如，使用 Claude Code 或 Codex 时，`/compact focus on the authentication changes` 会在压缩对话的同时在摘要中强调认证相关的工作。
</Tip>

## 按 Agent 分类的可用命令

可用的斜杠命令取决于你使用的编码 Agent。Vibe Kanban 会发现并暴露与 Agent 原生 CLI 中相同的命令，因此体验与你习惯的一致。

<Note>
某些需要 TUI 交互的内置命令（如 `/model` 或 `/theme`）目前在 Vibe Kanban 中不受支持。只有非交互式命令可用。
</Note>

### Claude Code

Claude Code 提供内置命令、用户定义命令和技能。完整详情请参阅[内置命令](https://code.claude.com/docs/en/interactive-mode#built-in-commands)和[技能](https://code.claude.com/docs/en/skills)文档。

| 命令 | 描述 |
|------|------|
| `/compact` | 清除对话历史但保留摘要到上下文中 |
| `/review` | 审查一个 Pull Request |
| `/security-review` | 对待处理的变更进行完整的安全审查 |
| `/init` | 初始化一个新的 CLAUDE.md 文件及代码库文档 |
| `/pr-comments` | 获取 GitHub Pull Request 的注释 |
| `/context` | 可视化当前上下文使用量 |
| `/cost` | 显示当前会话的总成本和持续时间 |
| `/release-notes` | 查看发布说明 |

你安装的任何自定义命令或技能也会出现在自动补全中。

### OpenAI Codex

Vibe Kanban 提供了 Codex 内置命令的精选子集。完整上游列表请参阅 [Codex 斜杠命令文档](https://developers.openai.com/codex/cli/slash-commands/)。

| 命令 | 描述 |
|------|------|
| `/compact` | 总结对话以释放 Token |
| `/init` | 在当前目录中生成 AGENTS.md 脚手架 |
| `/status` | 显示会话配置和 Token 使用量 |
| `/mcp` | 列出已配置的 MCP 工具 |
| `/model` | 查看或切换活跃模型 |
| `/fast` | 切换或检查快速模式 |

### OpenCode

OpenCode 提供内置命令和自定义命令。完整详情请参阅[内置命令](https://opencode.ai/docs/tui/#commands)和[自定义命令](https://opencode.ai/docs/commands)文档。

| 命令 | 描述 |
|------|------|
| `/compact` | 压缩会话 |
| `/commands` | 显示所有可用命令 |
| `/models` | 列出可用模型 |
| `/agents` | 列出可用 Agent |
| `/status` | 显示状态信息 |
| `/mcp` | 显示 MCP 服务器状态 |

## 命令发现

当你选择 Agent 时，Vibe Kanban 会自动发现可用的斜杠命令。在此过程中，你会在自动补全中看到"正在发现命令..."。

命令按工作空间和 Agent 缓存，因此后续使用是即时的。

<Info>
如果你在 Agent 配置中添加了新的自定义命令，切换到不同的 Agent 再切回来，或创建新会话来刷新命令列表。
</Info>

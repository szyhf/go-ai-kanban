任务尝试代表一次编程代理针对某个任务的会话。大多数任务只需要一次尝试，但有时你可能需要额外的尝试来重新开始。

## 何时创建新任务尝试

在以下情况下创建新的任务尝试：

- 一次尝试不成功后想用不同的方法**从头开始**
- 想尝试**不同的编程代理**（如从 Claude 切换到 Codex）
- 想使用**不同的代理配置或变体**以获得特定行为
- 想从**不同的基础分支**开始工作，以纳入最新的更改
- 想要**重置对话上下文**，完全重新开始

<Tip>
大多数用户每个任务只需要一次尝试。只有在第一次尝试效果不如预期时才创建额外的尝试。
</Tip>

## 创建额外的尝试

要为现有任务创建新的任务尝试：

<Steps>
<Step title="导航到任务">
  打开需要重新尝试的任务。
</Step>

<Step title="点击 Create New Attempt">
  点击任务右上角的三点图标，然后选择 **Create New Attempt**。
</Step>

<Step title="配置尝试">
  选择你的代理配置、变体和基础分支。这些可以与之前的尝试不同。
</Step>

<Step title="开始执行">
  点击 **Create Attempt** 以使用新配置开始全新的执行。
</Step>
</Steps>

## 对子任务的影响

<Warning>
创建新任务尝试会影响子任务。子任务关联的是特定的任务尝试，而不是任务本身。
</Warning>

当你创建新的任务尝试时：

- **已有的子任务**仍然关联到其原始的父尝试
- 从新尝试创建的**新子任务**将使用新尝试的分支作为基础

<Info>
有关子任务如何与任务尝试配合使用的更多详情，请参阅[创建子任务](/core-features/subtasks)。
</Info>

Vibe Kanban Cloud 使用 OAuth 身份认证，允许你使用现有的 GitHub 或 Google 账户登录，而无需创建新密码。

## 身份认证工作原理

<Info>
**什么是 OAuth？**

OAuth 是一种安全的应用登录方式，使用你已有的账户来验证身份。当你点击"Sign in with GitHub"时，你会被重定向到 GitHub 确认是否允许 Vibe Kanban 访问。GitHub 随后告知 Vibe Kanban 你的身份信息，而 Vibe Kanban 不会看到你的 GitHub 密码。
</Info>

### 登录流程

<Steps>
<Step title="点击登录">
  在登录页面，点击 **Sign in with GitHub** 或 **Sign in with Google**。

  <Frame>
    <img src="/images/cloud/sign-in-dialog.png" alt="Sign in dialog with GitHub and Google options" />
  </Frame>
</Step>

<Step title="在提供商页面授权">
  你将被重定向到 GitHub 或 Google。如果尚未登录，需要先登录。

  点击 **Authorize**（GitHub）或 **Allow**（Google）以授予 Vibe Kanban 访问权限。
</Step>

<Step title="自动跳转回来">
  授权完成后，你将自动跳转回 Vibe Kanban 并完成登录。
</Step>
</Steps>

### Vibe Kanban 可以访问什么

当你授权 Vibe Kanban 时，它仅请求最小权限：

| 提供商 | 授权范围 |
|----------|----------------|
| **GitHub** | 你的公开资料（姓名、邮箱、头像） |
| **Google** | 你的基本资料（姓名、邮箱、头像） |

<Info>
Vibe Kanban **不会**：
- 访问你的私有仓库（除非你之后额外授权）
- 以你的名义发布内容
- 修改你的账户设置
- 查看你的密码
</Info>

## 登录

### 首次登录

首次登录时：

1. 点击登录按钮（GitHub 或 Google）
2. 在提供商网站上授权应用
3. 系统会自动为你创建一个个人组织


### 再次登录

后续登录时：

1. 点击之前使用过的登录按钮
2. 如果你已在提供商处登录，将自动完成登录
3. 你将进入组织的仪表板

<Tip>
**提示：** 如果你已在浏览器中登录了 GitHub 或 Google，点击登录按钮即可几乎瞬间完成登录，无需任何提示。
</Tip>

## 退出登录

退出登录的步骤：

1. 点击左侧边栏底部的**头像图标**
2. 点击 **Sign out**

<Frame>
  <img src="/images/cloud/user-menu.png" alt="User menu showing Sign out option" />
</Frame>


<Warning>
退出登录仅影响当前浏览器。如果你在多个设备上登录，其他设备上的登录状态不受影响。
</Warning>

### 在所有设备上退出

目前不支持一次性在所有设备上退出。如果你需要撤销所有会话（例如怀疑账户被未授权访问）：

1. 前往你的 OAuth 提供商设置页面：
   - **GitHub:** [github.com/settings/applications](https://github.com/settings/applications)
   - **Google:** [myaccount.google.com/permissions](https://myaccount.google.com/permissions)
2. 找到"Vibe Kanban Cloud"并撤销访问权限
3. 所有会话将立即失效

## 多个账户

### 使用不同的提供商

你可以使用 GitHub 或 Google 登录——它们被视为独立的账户。如果你先用 GitHub 登录，后来又用 Google 登录，你将拥有两个独立的账户。

<Warning>
**目前不支持账户关联。** 如果你同时想使用 GitHub 和 Google，请选择其中一个并坚持使用，以避免出现重复账户。
</Warning>

### 切换账户

切换到不同账户的步骤：

1. 退出当前账户
2. 使用其他提供商或账户登录

如果你需要使用与浏览器记忆中不同的 GitHub/Google 账户登录：

1. 退出 Vibe Kanban
2. 前往提供商网站（github.com 或 google.com）
3. 在那里退出登录
4. 返回 Vibe Kanban 登录——系统会提示你登录提供商账户

## 故障排除

<AccordionGroup>
<Accordion title="'Invalid redirect URI' 错误">
**问题：** 点击登录后，出现关于无效重定向 URI 的错误。

**原因：** OAuth 应用中的回调 URL 不匹配。

**解决方案：**
1. 检查你的 OAuth 应用设置
2. 确保回调 URL 完全正确：
   - GitHub: `https://<your-public-base-url>/v1/oauth/github/callback`
   - Google: `https://<your-public-base-url>/v1/oauth/google/callback`
3. 不要有末尾斜杠，大小写必须完全一致
</Accordion>

<Accordion title="'Access denied' 错误">
**问题：** 提供商显示"access denied"或类似信息。

**原因：** 你点击了"Deny"而不是"Authorize"，或者你的组织有 OAuth 应用限制。

**解决方案：**
1. 重新尝试并点击"Authorize"或"Allow"
2. 如果你所在的 GitHub 组织有应用限制，请联系管理员批准 Vibe Kanban
</Accordion>

<Accordion title="登录到了错误的账户">
**问题：** 你使用了错误的 GitHub/Google 账户登录。

**解决方案：**
1. 退出 Vibe Kanban
2. 前往 github.com 或 google.com 并在那里退出登录
3. 在提供商处登录正确的账户
4. 返回 Vibe Kanban 并登录
</Accordion>

<Accordion title="会话意外过期">
**问题：** 你反复被退出登录。

**可能的原因：**
- 服务器重启（会使所有会话失效）
- JWT 密钥被更改
- 你已超过 7 天未活动

**解决方案：**
重新登录即可。如果问题持续出现，检查服务器是否频繁重启。
</Accordion>

<Accordion title="撤销访问后无法登录">
**问题：** 你在 GitHub/Google 上撤销了 Vibe Kanban 的访问权限，现在无法登录。

**解决方案：**
直接重新登录——系统会提示你重新授权应用。
</Accordion>
</AccordionGroup>

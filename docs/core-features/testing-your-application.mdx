## 概述

预览模式在 Vibe Kanban 中提供了嵌入式浏览器体验，让你无需离开开发环境即可测试和迭代你的 Web 应用。此功能通过提供实时预览能力和精确的组件选择工具，消除了在浏览器和 Vibe Kanban 之间切换的需要。

**主要优势：**
- **嵌入式预览**：直接在 Vibe Kanban 中查看正在运行的应用
- **精确的组件选择**：点击选择特定的 UI 组件以提供针对性反馈
- **开发服务器日志**：在底部通过可展开/折叠的日志监控开发服务器输出
- **无缝工作流**：无需在工具之间切换

## 设置预览模式

<Steps>
<Step title="配置开发服务器脚本">
  导航到你的项目设置，配置启动本地开发环境的开发服务器脚本。

  **常见示例：**
  - `npm run dev`（Vite、Next.js）
  - `npm start`（Create React App）
  - `yarn dev`（Yarn 项目）
  - `pnpm dev`（PNPM 项目）

  <Frame>
  <img src="/images/preview-mode-dev-script-config.png" alt="开发服务器脚本配置界面" />
  </Frame>

  <Info>
  你可能还需要配置 setup 脚本（如 `npm install`），以便在开发服务器启动之前安装依赖。在项目设置的 Setup Scripts 中配置。
  </Info>

  <Tip>
  确保你的开发服务器将 URL（如 `http://localhost:3000`）输出到 stdout/stderr，以便自动检测。
  </Tip>
</Step>

<Step title="安装 Web Companion">
  要使用精确的组件选择功能，请在你的应用中安装 `vibe-kanban-web-companion` 包。

  <Info>
  **推荐方式**：使用 Preview 标签页中的"Install companion automatically"按钮，让 Vibe Kanban 创建一个任务来自动安装和配置 companion。

  <Frame>
  <img src="/images/preview-mode-install-companion-button.png" alt="Preview 标签页中自动安装 companion 的按钮" />
  </Frame>
  </Info>

  **手动安装：**

  在你的项目中添加依赖：
  ```bash
  npm install vibe-kanban-web-companion
  ```

  然后将 companion 添加到你的应用中：

  <Tabs>
  <Tab title="Create React App">
    添加到你的 `src/index.js` 或 `src/index.tsx`：
    ```jsx
    import { VibeKanbanWebCompanion } from 'vibe-kanban-web-companion';
    import React from 'react';
    import ReactDOM from 'react-dom/client';
    import App from './App';

    const root = ReactDOM.createRoot(document.getElementById('root'));
    root.render(
      <React.StrictMode>
        <VibeKanbanWebCompanion />
        <App />
      </React.StrictMode>
    );
    ```
  </Tab>

  <Tab title="Next.js">
    添加到你的 `pages/_app.js` 或 `pages/_app.tsx`：
    ```jsx
    import { VibeKanbanWebCompanion } from 'vibe-kanban-web-companion'
    import type { AppProps } from 'next/app'

    function MyApp({ Component, pageProps }: AppProps) {
      return (
        <>
          <VibeKanbanWebCompanion />
          <Component {...pageProps} />
        </>
      )
    }
    ```
  </Tab>

  <Tab title="Vite">
    添加到你的 `src/main.jsx` 或 `src/main.tsx`：
    ```jsx
    import { VibeKanbanWebCompanion } from "vibe-kanban-web-companion";
    import React from "react";
    import ReactDOM from "react-dom/client";
    import App from "./App";

    ReactDOM.createRoot(document.getElementById("root")).render(
      <React.StrictMode>
        <VibeKanbanWebCompanion />
        <App />
      </React.StrictMode>
    );
    ```
  </Tab>
  </Tabs>

  <Note>
  Web Companion 会在生产构建中被自动 tree-shake，因此它只在开发模式下运行。
  </Note>
</Step>

<Step title="启动开发服务器">
  在 Preview 部分，点击 **Start Dev Server** 按钮启动你的开发服务器。

  <Frame>
  <img src="/images/preview-mode-start-dev-server.png" alt="从任务界面启动开发服务器" />
  </Frame>

  系统将会：
  - 启动你配置的开发脚本
  - 检测你的网站 URL 并加载它
</Step>
</Steps>

## 使用预览模式

### 访问预览

当你的开发服务器正在运行且 URL 被检测到后：

1. **点击 Preview 按钮**（眼睛图标）在任务界面中
2. **在 iframe 中查看嵌入的应用**
3. **直接在 Vibe Kanban 中与你的应用交互**

<Frame>
<img src="/images/vk-preview-interface.png" alt="预览模式，显示带有工具栏控件的嵌入式应用" />
</Frame>

### 预览工具栏控件

预览工具栏提供了管理预览体验的基本控件：

<Frame>
<img src="/images/vk-preview-toolbar.png" alt="预览工具栏，显示刷新、复制 URL、在浏览器中打开和停止服务器控件" />
</Frame>

- **Refresh**：重新加载预览 iframe
- **Copy URL**：将开发服务器 URL 复制到剪贴板
- **Open in Browser**：在默认浏览器中打开应用
- **Stop Dev Server**：停止正在运行的开发服务器

### 开发服务器日志

在 Preview 面板底部，你会找到可以展开或折叠的开发服务器日志。这些日志显示来自开发服务器的实时输出，方便你在不离开预览的情况下监控服务器活动、错误和调试信息。

<Frame>
<img src="/images/vk-dev-server-logs.png" alt="开发服务器日志，显示预览底部可展开/折叠的日志输出" />
</Frame>

### 组件选择

安装 Web Companion 后，你可以精确选择 UI 组件以提供针对性反馈：

<Steps>
<Step title="激活选择模式">
  点击应用右下角浮动的 Vibe Kanban companion 按钮来激活组件选择模式。

  <Frame>
  <img src="/images/vk-component-selection.png" alt="组件选择界面，显示可选择的已高亮元素" />
  </Frame>
</Step>

<Step title="选择组件层级">
  当你点击一个组件时，Vibe Kanban 会显示从最内层到最外层的组件层级。选择适合你反馈的层级：

  - **内部组件**：用于特定的 UI 元素（按钮、输入框）
  - **外部组件**：用于更大的部分（卡片、布局）

  <Frame>
  <img src="/images/preview-mode-component-depth.png" alt="组件层级选择，显示可选择的组件层级结构" />
  </Frame>
</Step>

<Step title="提供针对性反馈">
  选择组件后，撰写你的后续消息。编程代理将收到：
  - **精确的 DOM 选择器** 信息
  - **组件层级** 和源文件位置
  - **你的具体指令** 关于需要更改什么

  <Check>
  无需描述"右上角的那个按钮"——代理确切知道你指的是哪个组件！
  </Check>
</Step>
</Steps>

## 故障排除

如果预览没有自动加载，请确保你的开发服务器将 URL 输出到 stdout/stderr 以便自动检测。

支持的 URL 格式：
- `http://localhost:3000`
- `https://localhost:3000`
- `http://127.0.0.1:3000`
- `http://0.0.0.0:5173`

<Note>
使用 `0.0.0.0` 或 `::` 的 URL 会自动转换为 `localhost` 以便嵌入。
</Note>

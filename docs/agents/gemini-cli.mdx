description: "设置 Google Gemini CLI"

---

<Steps>
<Step title="运行 Gemini CLI">
  ```bash
  npx -y @google/gemini-cli
  ```
</Step>

<Step title="按照登录指引操作">
  按照提示完成身份验证流程。更多详情请参阅 [geminicli.com](https://geminicli.com/)。
</Step>

<Step title="启动 Vibe Kanban">
  完成身份验证后，启动 Vibe Kanban：

  ```bash
  npx vibe-kanban
  ```

  现在你可以在创建任务尝试时选择 Gemini CLI。
</Step>
</Steps>

<Steps>
<Step title="运行 Qwen Code">
  ```bash
  npx -y @qwen-code/qwen-code
  ```
</Step>

<Step title="按照登录指引操作">
  按照提示完成身份验证流程。更多详情请参阅 [Qwen 官方文档](https://github.com/QwenLM/qwen-code)。
</Step>

<Step title="启动 Vibe Kanban">
  完成身份验证后，启动 Vibe Kanban：

  ```bash
  npx vibe-kanban
  ```

  现在你可以在创建任务尝试时选择 Qwen Code。
</Step>
</Steps>

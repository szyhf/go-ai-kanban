---
title: "Claude Code"
description: "设置 Anthropic 的 Claude Code agent"
icon: https://www.vibekanban.com/images/logos/claude.svg#"
---

<Steps>
<Step title="运行 Claude Code">
  ```bash
  npx -y @anthropic-ai/claude-code
  ```
</Step>

<Step title="按照登录指引操作">
  按照提示完成身份验证流程。更多详情请参阅 [Claude Code 文档](https://docs.claude.com/en/docs/claude-code/quickstart)。
</Step>

<Step title="启动 Vibe Kanban">
  完成身份验证后，启动 Vibe Kanban：

  ```bash
  npx vibe-kanban
  ```

  现在你可以在创建任务尝试时选择 Claude Code。
</Step>
</Steps>

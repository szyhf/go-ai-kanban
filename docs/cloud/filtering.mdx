随着项目增长，你需要快速查找特定事项的方法。筛选栏提供强大的搜索、筛选和排序功能，帮助你专注于重要内容。


## 筛选栏

筛选栏位于看板上方，包含：

- **搜索字段** - 按文本查找事项
- **筛选下拉菜单** - 按优先级、负责人、标签筛选
- **排序下拉菜单** - 更改事项排列顺序
- **Clear All 按钮** - 重置所有筛选

## 搜索

在搜索字段中输入文字以按标题查找事项。


### 搜索工作原理

- 搜索仅匹配事项**标题**
- 搜索**不区分大小写**（"Login"匹配"login"）
- 搜索支持**部分匹配**（"log"匹配"Login flow"）
- 输入时即时更新结果

### 高效搜索技巧

- 搜索标题中的关键词
- 使用 Simple ID 查找特定事项（例如"TASK-123"）
- 将搜索与筛选器结合使用以获得精确结果

<Tip>
如果找不到某个事项，请检查筛选器是否将其隐藏。点击 **Clear All** 重置筛选器后重新搜索。
</Tip>

## 筛选

筛选器让你只显示符合特定条件的事项。

### 优先级筛选

按优先级筛选事项：

<Frame>
  <img style={{maxHeight: "350px"}} src="/images/cloud/filter-priority.png" alt="Priority filter dropdown showing Urgent, High, Medium, and Low options" />
</Frame>

| 优先级 | 颜色 | 说明 |
|----------|--------|-------------|
| **Urgent** | 红色 | 需要立即关注 |
| **High** | 橙色 | 重要，尽快处理 |
| **Medium** | 黄色 | 普通优先级 |
| **Low** | 灰色 | 可以等待 |

**按优先级筛选：**
1. 点击 **Priority** 下拉菜单
2. 选择一个或多个优先级
3. 只显示匹配的事项

### 负责人筛选

按负责人筛选事项：

<Frame>
  <img style={{maxHeight: "350px"}} src="/images/cloud/filter-assignee.png" alt="Assignee filter dropdown showing team members" />
</Frame>

**选项：**
- **指定团队成员** - 显示分配给所选人员的事项
- **Unassigned** - 显示未分配的事项

**按负责人筛选：**
1. 点击 **Assignee** 下拉菜单
2. 选择一个或多个团队成员，或选择"Unassigned"
3. 只显示匹配的事项

<Info>
如果你选择了多个负责人，分配给其中**任意一人**的事项都会显示（OR 逻辑）。分配给 Alice 和 Bob 的事项在筛选其中任一人时都会显示。
</Info>

### 标签筛选

按标签筛选事项：

<Frame>
  <img style={{maxHeight: "350px"}} src="/images/cloud/filter-tags.png" alt="Tags filter dropdown showing available tags" />
</Frame>

**按标签筛选：**
1. 点击 **Tags** 下拉菜单
2. 选择一个或多个标签
3. 只显示包含至少一个所选标签的事项

### 组合筛选

你可以同时使用多个筛选器：

- 同一类别的筛选器使用 **OR** 逻辑
  - 优先级：Urgent OR High → 同时显示两者
- 不同类别的筛选器使用 **AND** 逻辑
  - 优先级：Urgent AND 负责人：Alice → 显示分配给 Alice 的紧急事项

**示例：** 查找分配给你的高优先级 Bug：
1. 将 Priority 设为"High"和"Urgent"
2. 将 Assignee 设为你自己
3. 将 Tags 设为"Bug"

## 排序

控制每列中事项的排列顺序。

<Frame>
  <img style={{maxHeight: "350px"}} src="/images/cloud/sort-dropdown.png" alt="Sort dropdown showing Manual, Priority, Created, Updated, and Title options" />
</Frame>

### 排序选项

| 排序方式 | 说明 |
|---------|-------------|
| **Manual** | 你的自定义顺序（拖动重新排序） |
| **Priority** | Urgent 优先，然后是 High、Medium、Low |
| **Created** | 最新或最旧优先 |
| **Updated** | 最近更改的优先 |
| **Title** | 字母顺序 |

### 排序方向

点击排序方向按钮切换：
- **升序**（↑） - A→Z、最旧优先、低→紧急
- **降序**（↓） - Z→A、最新优先、紧急→低

### 手动排序模式

当排序设置为 **Manual** 时：
- 你可以拖动事项在列内重新排序
- 你的自定义顺序会被保存并与团队共享
- 这是大多数工作流的默认模式

<Warning>
如果你从 Manual 排序切换到其他方式，你**无法**拖动重新排序事项。顺序由所选排序字段决定。
</Warning>

## 清除筛选

### 全部清除

点击 **Clear All** 按钮一次性重置所有筛选和搜索。这将显示项目中的所有事项。


### 清除单个筛选

清除单个筛选器：
1. 点击筛选下拉菜单
2. 取消选择所有选项

要清除搜索字段，点击搜索框内的 **x** 按钮。

## 筛选持久性

你的筛选和排序设置在当前会话中会保存：
- 导航离开后返回时筛选保持不变
- 切换项目时筛选重置
- 退出登录时筛选重置

<Info>
筛选是个人设置——不会影响其他团队成员看到的内容。每个人都可以有自己的筛选设置。
</Info>

## 常见筛选场景

<AccordionGroup>
<Accordion title="只显示分配给我的事项">
1. 点击 **Assignee** 下拉菜单
2. 选择你的名字
3. 所有列中只显示你的事项
</Accordion>

<Accordion title="查找需要关注的紧急事项">
1. 点击 **Priority** 下拉菜单
2. 选择"Urgent"
3. 可选：也选择"High"以包含高优先级事项
</Accordion>

<Accordion title="查看所有 Bug">
1. 点击 **Tags** 下拉菜单
2. 选择"Bug"标签（或你的等效标签）
3. 显示所有 Bug 事项
</Accordion>

<Accordion title="查找未分配的工作">
1. 点击 **Assignee** 下拉菜单
2. 选择"Unassigned"
3. 浏览可用事项并为自己分配一个
</Accordion>

<Accordion title="查看最近更新的事项">
1. 点击 **Sort** 下拉菜单
2. 选择"Updated"
3. 将方向设为降序（最新优先）
4. 最近更改的事项显示在每列的顶部
</Accordion>
</AccordionGroup>

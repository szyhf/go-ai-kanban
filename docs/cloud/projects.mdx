项目是你工作所在的地方。每个项目包含一个带有事项、状态和标签的看板，帮助你组织和跟踪进度。

<Frame>
  <img src="/images/cloud/project-kanban-board.png" alt="Project kanban board showing columns and issues" />
</Frame>

## 什么是项目？

一个**项目**是你组织内相关工作的容器。可以把它看作是针对特定计划、产品或团队目标的专属空间。

每个项目包含：
- **Issues** - 单项工作（Bug、功能、任务）
- **Statuses** - 看板上的列（To Do、In Progress、Done 等）
- **Tags** - 用于分类事项的标签
- **团队访问** - 所有组织成员都可以查看和处理项目事项

## 项目侧边栏

左侧边栏提供对项目和 workspace 的快速访问。

<Frame>
  <img style={{maxHeight: "350px"}} src="/images/cloud/sidebar-workspaces.png" alt="Project sidebar showing Workspaces icon, project icons, and add button" />
</Frame>

### 侧边栏元素

| 元素 | 说明 |
|---------|-------------|
| **Workspaces 图标** | 顶部图标 - 打开 Workspaces 视图，用于编码代理 |
| **项目图标** | 显示项目缩写的方形按钮（例如"VI"代表 vibe-kanban） |
| **+ 按钮** | 创建新项目 |

### 项目图标

每个项目显示为带有项目名称两个字母缩写的方形按钮。当前选中的项目会高亮显示。

<Frame>
  <img style={{maxHeight: "350px"}} src="/images/cloud/sidebar-project-tooltip.png" alt="Hovering over project icon shows full project name" />
</Frame>

将鼠标悬停在任意项目图标上可以看到完整项目名称的提示框。

## 创建项目

<Steps>
<Step title="打开你的组织">
  登录并从侧边栏或组织切换器中选择你的组织。
</Step>

<Step title="点击创建项目">
  点击侧边栏或项目页面中的 **+ New Project** 按钮。

</Step>

<Step title="输入项目详情">
  填写项目信息：

  <Frame>
    <img style={{maxHeight: "300px"}} src="/images/cloud/create-project-dialog.png" alt="Create Project dialog with name and colour fields" />
  </Frame>

  | 字段 | 说明 |
  |-------|-------------|
  | **Name** | 项目的清晰名称（例如"Mobile App"、"Q1 Marketing"） |
  | **Colour** | 点击色块为此项目选择颜色 |
</Step>

<Step title="点击创建">
  点击 **Create Project** 创建项目。你将进入新项目的看板。
</Step>
</Steps>

## 默认状态

新项目附带六个默认状态列：

| 状态 | 用途 | 默认可见 |
|--------|---------|-------------------|
| **Backlog** | 想法和未来工作 | 隐藏 |
| **To do** | 准备开始的事项 | ✓ |
| **In progress** | 正在进行的事项 | ✓ |
| **In review** | 等待代码审查 | ✓ |
| **Done** | 已完成的事项 | ✓ |
| **Cancelled** | 不会完成的事项 | 隐藏 |

<Info>
隐藏状态不会作为列显示在看板上，但你仍然可以通过状态标签页（例如"Backlog"或"Cancelled"标签）访问其中的事项。
</Info>

<Frame>
  <img src="/images/cloud/project-kanban-board.png" alt="Project kanban board showing columns and issues" />
</Frame>

你可以自定义这些状态——重命名、更改颜色、添加新状态或隐藏不用的。详见[自定义看板](/cloud/customisation)。

## 项目设置

通过点击项目名称旁边的齿轮图标（<Icon icon="gear" />）访问项目设置。

<Frame>
  <img style={{maxHeight: "250px"}} src="/images/cloud/project-settings-icon.png" alt="Project header showing settings gear icon" />
</Frame>

### 重命名项目

1. 打开项目设置
2. 编辑 **Project name** 字段
3. 点击 **Save**

### 更改项目颜色

1. 打开项目设置
2. 点击颜色选择器
3. 选择新颜色
4. 点击 **Save**

<Frame>
  <img style={{maxHeight: "200px"}} src="/images/cloud/edit-project-form.png" alt="Edit project form with name and colour picker" />
</Frame>

颜色显示在侧边栏中，帮助你快速识别项目。

<Tip>
你也可以从 **Settings** → **Remote Projects** 管理项目。详见[远程项目设置](/settings/remote-projects)。
</Tip>

## 在项目之间切换

你有多种方式切换项目：

**从侧边栏：**
- 点击侧边栏中的任意项目名称打开它

**从项目下拉菜单：**
- 点击标题中的当前项目名称
- 从下拉菜单中选择不同的项目


## 删除项目

<Warning>
删除项目是永久性操作，无法撤销。项目内的所有事项、评论和数据都将被删除。
</Warning>

要删除项目，前往 **Settings** → **Remote Projects**：

<Steps>
<Step title="打开远程项目设置">
  前往 **Settings** 并从侧边栏选择 **Remote Projects**。
</Step>

<Step title="找到项目">
  选择组织并找到你想要删除的项目。
</Step>

<Step title="打开菜单">
  将鼠标悬停在项目上并点击 **...**（三个点）菜单。

  <Frame>
    <img style={{maxHeight: "150px"}} src="/images/cloud/project-menu-button.png" alt="Project row showing three-dots menu button" />
  </Frame>
</Step>

<Step title="点击删除">
  从菜单中选择 **Delete** 并在提示时确认。

  <Frame>
    <img style={{maxHeight: "150px"}} src="/images/cloud/project-delete-menu.png" alt="Dropdown menu with Delete option" />
  </Frame>
</Step>
</Steps>

<Info>
删除前，请考虑你是否可能需要任何事项或其历史记录。已删除的项目无法恢复。
</Info>

有关管理项目的更多详情，请参见[远程项目设置](/settings/remote-projects)。

## 最佳实践

<CardGroup cols={2}>
<Card title="每个计划一个项目" icon="folder">
  为不同的计划创建独立的项目，而不是把所有内容放在一个项目中。这使你的看板保持聚焦和可管理。
</Card>

<Card title="使用描述性名称" icon="tag">
  选择能清晰描述项目内容的项目名称。"Mobile App v2"比"Project A"更好。
</Card>

<Card title="保持状态列一致" icon="columns">
  尽量在不同项目中使用相似的状态列，这样团队成员在项目之间切换时不会感到困惑。
</Card>

<Card title="归档已完成的工作" icon="box-archive">
  事项完成后，你可以隐藏 Done 列或创建 Archive 状态以保持看板整洁。
</Card>
</CardGroup>

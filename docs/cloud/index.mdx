## 什么是 Vibe Kanban Cloud？

**Vibe Kanban Cloud** 为 Vibe Kanban 增加了团队协作功能。你的项目、事项和进度同步到云端，让整个团队保持同步。

### 核心优势

<CardGroup cols={2}>
<Card title="团队协作" icon="users">
  邀请团队成员，在相同的项目上协同工作。每个人都能实时看到更新。
</Card>

<Card title="随时随地工作" icon="globe">
  你的数据同步到云端。通过登录即可从任何电脑访问你的项目。
</Card>

<Card title="实时同步" icon="bolt">
  更改对所有团队成员即时可见。无需刷新或手动同步。
</Card>

<Card title="相同界面" icon="desktop">
  Cloud 使用你已熟悉的 Vibe Kanban 界面。无需学习新工具。
</Card>
</CardGroup>

### Cloud 与本地版对比

| 功能 | 本地版 | Cloud |
|---------|-------|-------|
| **数据存储** | 在你的电脑上 | 同步到云端 |
| **团队访问** | 仅你个人 | 可邀请团队成员 |
| **是否需要登录** | 否 | 是（GitHub 或 Google） |
| **实时协作** | 否 | 是 |
| **离线使用** | 是 | 需要网络 |

<Info>
你可以在同一个 Vibe Kanban 安装中同时使用本地项目和 Cloud 项目。它们显示在侧边栏的不同区域。
</Info>

## 工作原理

1. 像往常一样**运行 Vibe Kanban**：`npx vibe-kanban`
2. 使用 GitHub 或 Google 账户**登录**（会自动创建个人组织）
3. 在个人工作空间中**创建项目**
4. 如果需要协作，**创建团队组织**（可选）
5. 通过邮件**邀请团队成员**并实时协作

你的本地项目保持不变。Cloud 项目独立存储并自动同步。

## 核心概念

### 组织

一个**组织**是你团队的共享空间。它包含：
- 拥有不同角色的团队成员（Admin、Member）
- 所有人都可以访问的项目
- 共享设置

可以把它看作是你在 Vibe Kanban 中的公司或团队。

### 项目

一个**项目**是针对特定工作目标的看板。每个项目包含：
- 可自定义的状态列
- 用于跟踪工作的事项
- 用于分类的标签

### 事项

一个**事项**是一单项工作。与本地任务不同，Cloud 事项拥有：
- Simple ID（如 `TASK-123`）方便引用
- 多个负责人
- 优先级
- 用于讨论的评论
- 用于分解工作的子事项

## 功能特性

### 团队协作
- 通过邮件邀请成员
- 基于角色的权限（Admin 和 Member）
- 查看谁负责什么

### 实时同步
- 更改对所有人即时可见
- 无冲突或手动合并
- 始终保持最新状态

### 高级看板
- 在列之间拖放事项
- 带颜色的自定义状态列
- 按优先级、负责人或标签筛选
- 多种排序选项

### GitHub 集成
- 将 Pull Request 关联到事项
- 直接在 Vibe Kanban 中审查代码
- 跟踪 PR 状态

## 开始使用

<Steps>
<Step title="运行 Vibe Kanban">
  ```bash
  npx vibe-kanban
  ```
</Step>

<Step title="登录">
  点击 **Login** 并使用 GitHub 或 Google 登录。系统会自动创建个人组织。
</Step>

<Step title="创建项目">
  点击 **+ New Project** 开始添加事项。
</Step>

<Step title="创建团队组织（可选）">
  如需协作，从用户菜单创建新组织并通过邮件邀请成员。
</Step>
</Steps>
